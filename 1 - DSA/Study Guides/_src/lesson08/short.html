Short note: revision sheet

TopicRemember
RecursionAn algorithm that calls itself on a smaller problem; needs a base case. Tree algorithms are recursive.
TreeA set of nodes holding atomic or composite data, connected by edges. Root = top node; leaf = no children; order = maximum children a node can have.
Binary treeOrder 2. A finite set of elements partitioned into root, left subtree, right subtree (each again a binary tree).
TraversalVisit each node once and only once, in a predetermined sequence.
PreorderRoot, Left, Right (node visited when reached). Example tree: a b c d e f
InorderLeft, Root, Right (not visited until its left subtree is done). c b d a e f
PostorderLeft, Right, Root (not visited until both subtrees are done). c d b f e a
Binary search treeLeft subtree values < root; right subtree values ≥ root; every subtree a BST. Inorder traversal gives sorted order (a sorting algorithm).
BST exampleInsert 70, 50, 30, 80, 60, 40, 20. Preorder 70 50 30 20 40 60 80; inorder 20 30 40 50 60 70 80; postorder 20 40 30 60 50 80 70.
Array-based treeRoot at index 1; left child 2n; right child 2n + 1; 0 = empty. Create fills with 0. insert(d, n = 1) recursive. Traversals check n < size and p[n] ≠ 0.
Array tree problemHeight h needs 2h+1 elements (2h+1 − 1 nodes). Unbalanced: waste grows dramatically. Cannot grow, cannot shrink. OK if balanced / max height known.
Linked treeNode = data, left, right (null = none); root pointer. Can grow and shrink. Use when height unknown or tree unbalanced.
addNodeaddNode(REF p, d): if p = null create node (data, left = right = null); else if d < p->data go left else go right. C++: node *&p.
removeNodeRemove left, remove right, then release the node (children first).
ApplicationsHierarchical data (folders / files, land registry) · expression trees (parent = operator, children = operands) · data compression and encoding · efficient search of large dynamic data sets
Why a linked BSTArray + binary search: needs sorted data, inserting / deleting shifts elements. Linked list: easy insert / delete, slow search. Linked BST: insert / delete by changing addresses and fast search.
Expression tree orders3 + 5 × 2: inorder 3 + 5 × 2; preorder + 3 × 5 2; postorder 3 5 2 × +
Exam tipTo build a BST, insert in the given order, comparing at each node (left if smaller, right if equal or larger). For traversals, always recurse the whole subtree before moving on; the only difference is when the root is printed. If asked for sorted output, answer: inorder traversal.
