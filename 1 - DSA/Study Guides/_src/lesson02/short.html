Short note: revision sheet

TopicRemember
Space complexityMemory a program written with a particular algorithm needs to run to completion.
WhyWill available memory be enough? · Prefer the algorithm that uses less memory · Estimate the largest problem we can solve with the memory available.
ComponentsInstruction space · Data space · Environment stack space
Instruction spaceMemory for the compiled instructions. Depends on compiler, compiler options, target architecture.
Data spaceMemory for constants and variables. Depends on data types and the number of named constants, primitive variables and structured variables.
Environment stackData structure (LIFO) keeping what is needed to resume partly completed functions: return address, parameters, local variables. If f1 calls f2, it keeps a pointer to the calling instruction in f1.
Insensitive factorsInstruction space · literal constants, named constants, primitive variables · stack space of non-recursive functions
Sensitive factorsStructured variables and dynamic allocation (e.g. sorting n integers) · stack space of recursive functions (e.g. factorial)
FormulaS(n) = c + SA(n); c = constant part, SA = sensitive part, n = instance characteristic
Iterative sumOnly primitives, array by reference, non-recursive: SA = 0, so O(1)
Recursive sumn + 1 calls, each keeps n, a, return address (4 + 4 + 4 = 12 bytes on 32-bit): about 12(n + 1) bytes, O(n)
Sizeschar 1, short 2, int 4, long 4 (32-bit) / 8 (64-bit), float 4, double 8, pointer 4 (32-bit) / 8 (64-bit)
Exam tipWhen asked to analyse space: name which parts are sensitive and why (structured variable? recursion?), state the per-call frame size if recursive, then give S(n). Recursion is the usual source of a non-constant answer.
