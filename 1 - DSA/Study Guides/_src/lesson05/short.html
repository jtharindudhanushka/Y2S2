Short note: revision sheet

TopicRemember
Atomic data typeA set of non-decomposable data: a set of homogeneous data + a set of operations. Also called primitive. int, char, double...
Composite data typeA set of decomposable data composed using atomic and composite types; homogeneous or heterogeneous. struct Day, struct Person.
Atomic vs compositeCannot vs can be broken down · homogeneous only vs homogeneous or heterogeneous · building block vs built from other types
Data structureA structure that holds a set of atomic or composite data. Consists of a set of homogeneous or heterogeneous data and a set of operations.
Three partsData · Structure (arrangement) · Operations
Array exampleint num[] = {3,2,1}: homogeneous atomic; get num[0], set num[2] = 5
Array of struct examplePerson employee[]: heterogeneous, atomic + composite, linear; get employee[0].name, set employee[1].weight = 57
Coming nextStack (push, pop, LIFO) · Queue (enqueue, dequeue, FIFO) · Tree (nodes and edges)
Exam tipDefinitions are usually asked word for word: use the keywords non-decomposable, homogeneous, operations (atomic); decomposable, atomic and composite, homogeneous or heterogeneous (composite); holds a set of atomic or composite data, operations (data structure).
