Short note: revision sheet

TopicRemember
QueueLinear data structure; additions at one end (rear), removals at the other end (front). FIFO: First In First Out.
Operationsenqueue() adds at rear; dequeue() removes from front.
ErrorsOverflow: add to a full queue. Underflow: remove from an empty queue.
Array-based variablesp, size, count, front (first element), rear (cell after the last element)
Why count?front = rear both when empty and when full; count (0 / size) tells them apart.
Circular arrayImagine the array bent into a ring. After enqueue: rear ← rear + 1; rear ← rear MOD size. After dequeue: front ← front + 1; front ← front MOD size.
Array createsize ← s; front = rear = count = 0; allocate array
Array enqueueif full: false. p[rear] ← d; rear++; count++; rear MOD size; true
Array dequeueif empty: false. d ← p[front]; front++; count−−; front MOD size; true
Linked queueNode = data + next. front = first node, rear = last node. Empty: front = null. No fixed capacity.
Linked enqueuenew node p, data = d, next = null. If front ≠ null: rear->next ← p, else front ← p. Then rear ← p.
Linked dequeueif empty: false. d ← front->data; p ← front; if front = rear then front = rear = null, else front ← front->next; release p.
C++ bitsp[rear++] = d, d = p[front++], rear % size, (front ? rear->next : front) = p;
Costenqueue and dequeue: O(1)
ApplicationsProcess scheduling in an OS · printer spooling · network traffic handling · many data processing and service-providing applications (e.g. SMS gateway: linked list-based queue)
Exam tipStack = reverse / most recent first; queue = arrival order. If the question says "any number of items" choose the linked list-based version. When drawing a queue in memory show front and rear pointers and null at the end.
