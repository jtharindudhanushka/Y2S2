Short note: revision sheet

TopicRemember
StackLinear data structure; all additions (push) and removals (pop) at one end (top). LIFO: Last In First Out.
ErrorsOverflow: push on a full stack. Underflow: pop from an empty stack.
ChecksisFull() before push (array-based); isEmpty() before pop.
Operationscreate, destroy, isEmpty, isFull (array only), push, pop
Array-based variablesp (array pointer), size, top. Empty: top = −1. Full: top = size − 1.
Array push / poppush: top ← top + 1; p[top] ← d. pop: d ← p[top]; top ← top − 1. Both return false on overflow / underflow.
Array drawbackPredefined maximum capacity even if unused (static array: fixed at compile time; dynamic array: fixed after allocation). Wastes memory in most cases.
Linked stackNode = data + next. Only top pointer; bottom node's next = null; empty when top = null. Grows and shrinks at run time.
Linked pushp ← top; top ← new node; top->data ← d; top->next ← p
Linked popd ← top->data; p ← top; top ← top->next; release p
C++ bitsclass with constructor (create) and destructor (destroy); p[++top] = d (pre-increment); d = p[top--] (post-decrement); int pop(char &d) reference parameter; new[] / delete[]; top->data
Costpush and pop: constant number of steps, O(1)
ApplicationsReversing data · converting numbers · parsing data · converting expressions · evaluating expressions · backtracking
Reversingpush each char until '\0' (use s.push(ch) in the loop condition), then pop and print. Real uses: undo, browser back.
Decimal to binarypush n MOD 2, n ← n / 2 until 0; pop to print. 25 → 11001.
Bracket checkpush '(' ; on ')' pop (fail = mismatch); at end stack must be empty.
Postfix evaluationoperand → push. Operator → pop operand2 first, then operand1, push (operand1 op operand2). At '=' pop the result. 12+34+*= → 21. Integer stack.
Exam tipWhen asked for the data structure for a problem, justify it: "reverse order / most recent first / undo" means a stack. In postfix evaluation remember operand2 is popped first. Know both the array-based and the linked pseudocode by heart, including create and destroy.
