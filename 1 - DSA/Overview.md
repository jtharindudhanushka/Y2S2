# INTE 22343: Data Structures and Algorithms

- **Course Code:** INTE 22343
- **Course Title:** Data Structures and Algorithms
- **Prerequisites:** INTE 11223, INTE 12213

---

## Learning Outcomes
On completion of this course unit, you should be able to:
1. Identify the properties of a good algorithm and a good program.
2. Determine and analyze the efficiency of algorithms often used in computer programming.
3. Design correct and efficient algorithms for solving real-world problems.
4. Implement data structures often used in computer programming.
5. Discuss the real-world applications of different data structures.
6. Apply data structures for solving real-world problems.
7. Design and implement efficient computer programs using data structures and algorithms.

---

## Course Content
Algorithms and programs, correctness and efficiency of an algorithm, space and time complexities, the best, average and worst case complexities, linear, logarithmic, linear logarithmic, quadratic, polynomial, exponential and factorial functions, asymptotic notations, classical searching and sorting algorithms, divide-and-conquer approach, recursion, atomic and composite data types, fundamental data structures, advanced data structures, real-world applications.
