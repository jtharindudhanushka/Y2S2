# INTE 22283: Mobile Applications Development

- **Course Code:** INTE 22283
- **Course Title:** Mobile Applications Development
- **Department:** Department of Industrial Management, University of Kelaniya

---

## Course Curriculum & Topics
1. **Introduction to Mobile Computing:** Mobile ecosystems, network topologies, mobile constraints.
2. **Mobile Operating Systems:** Architecture of Android vs iOS, kernel level services, execution runtimes.
3. **Mobile Development Platforms:** Native (Android Studio, Kotlin/Java, Xcode, Swift) vs Cross-Platform (Flutter, React Native).
4. **Android Application Architecture:** Core components (Activities, Services, Broadcast Receivers, Content Providers), Android manifest, lifecycle management.
5. **UI/UX & Layout Design:** Android Layouts (ConstraintLayout, LinearLayout, RelativeLayout), Material Design guidelines.
6. **Data Display & Collections:** RecyclerView architecture, ViewHolders, Adapters, performance optimizations.
7. **Web Services & Network APIs:** REST API consumption, JSON parsing, asynchronous background threading.
8. **Smartphone Hardware Integration:** Location services (GPS, FusedLocationProvider), hardware sensors (accelerometer, gyroscope).
9. **Persistent Storage & Database Connectivity:** SQLite, Room Persistence Library, Shared Preferences.
10. **Testing & Debugging:** Unit testing, UI instrumentation tests, Android Logcat, memory leak profiling.
11. **iOS Overview & Cross-Platform Development:** Swift basics, iOS navigation, SwiftUI/UIKit overview.
