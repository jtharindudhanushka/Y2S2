1. What is reinforcement learning?

DefinitionReinforcement learning (RL) is a type of machine learning in which an agent learns by interacting with an environment and receiving feedback as rewards (+) or penalties (−). A positive reward means a desirable action; a negative reward (penalty) means an undesirable one.

Analogy: training a puppy. You give no rule book: if it sits, a treat (reward); if it jumps on the sofa, "no" (penalty). After many tries it learns which actions lead to treats. A game character falling in lava loses points; riding a bike you learn by trying and falling.

TypeWhat the machine getsPicture
SupervisedExamples with the correct answersA teacher with an answer sheet
UnsupervisedData with no answersSorting buttons into groups
ReinforcementOnly a reward or penalty after it actsLearning to ride a bike by trying and falling

In RL nobody tells the agent the right action; it must discover good actions by trying them, and a good action may only pay off later (a chess move that wins 30 moves later). That is why RL is harder than supervised learning.

Real examples

  • Robots: Boston Dynamics (first built for military use; four-legged robots like dogs) can use RL ideas to learn suitable movements through interaction and feedback.
  • Games: programs play millions of games and are rewarded for winning. Driving and control: steering, braking, route planning.
  • Chatbots: reward signals from human feedback make answers more helpful and human-like (the reinforcement-learning stage of Lesson 8's recipe for generative models).

The loop: the agent sees a state, picks an action; the environment returns a new state and a reward; the agent learns and acts again. The agent learns which action is best for a particular state.

Policy: π(s, ai) = Pi"In state s, the policy π chooses action ai with probability Pi." The probabilities for a state add up to 1.

Example in state s1 (in front of a step): π(s1, lift leg) = 0.7, π(s1, turn) = 0.2, π(s1, wait) = 0.1 (total 1.0). Learning means changing these probabilities so rewarded actions become more likely. (0.5, 0.4, 0.3 is not a valid policy: it adds up to 1.2.)

The tiny world used for the examples

A corridor of three squares: A (start), B, and C (goal, reward +10). From A the robot can only go right to B; from B it can go left (to A) or right (to C). The best policy is "always go right".

3. Reward, return and the discount factor (peer notes)

A single reward is not the goal; the goal is the total reward over an episode, the return. A chess move that wins a piece now might lose the game later, and a move that gives nothing now might set up a win.

A reward now is usually worth more than the same reward later, so later rewards are multiplied by the discount factor γ (0 to 1):

G = r1 + γ r2 + γ² r3 + …γ close to 1: patient agent; γ close to 0: cares only about rewards right now.
  • Corridor rewards 0, 0, then +10 on reaching C: with γ = 0.9, G = 0 + 0.9×0 + 0.81×10 = 8.1; with γ = 0.5, G = 0 + 0.5×0 + 0.25×10 = 2.5.
  • Rewards 0, 5 with γ = 0.8: G = 0 + 0.8 × 5 = 4.

Analogy: 100 rupees today is worth more than 100 rupees in a year; γ says how much less.

Value of a state = the return the agent can expect from that state if it follows its policy. Under "always go right": B is one step from the goal, so V(B) = 10; A is two steps away, so V(A) = 0.9 × 10 = 9. States nearer the reward have higher value.

4. Exploration versus exploitation (peer notes)

Should the agent exploit (repeat the action that has worked best so far) or explore (try something different that might be even better)? Analogy: your favourite restaurant versus the new one down the street. Too much exploiting misses better options; too much exploring wastes time.

ε-greedy ruleWith probability ε the agent explores (random action); otherwise (probability 1 − ε) it picks the action it currently thinks is best.

Example: 3 actions, ε = 0.3. Random exploration is shared among all 3 actions: 0.3 / 3 = 0.1 each. Best-known action: (1 − 0.3) + 0.1 = 0.8. Each other action: 0.1. Check: 0.8 + 0.1 + 0.1 = 1.0. With ε = 0.1 and 2 actions the best action has 0.9 + 0.05 = 0.95. A common plan: start with a large ε and shrink it as the agent learns. If it never explores, it can stay stuck with a mediocre action.

5. Q-learning (peer notes)

Q-learning keeps a table of Q-values: Q(s, a) = how good it is to take action a in state s (the expected return). The agent then picks the action with the highest Q.

Q(s, a) ← Q(s, a) + α [ r + γ · max Q(s′, a′) − Q(s, a) ]α = learning rate (step size); r = reward just received; γ = discount; max Q(s′, a′) = best Q-value in the next state s′. The bracket is the error: "what I just saw" minus "what I expected"; Q moves a fraction α of the way toward what was seen.

Worked example in the corridor

α = 0.5, γ = 0.9, all Q start at 0. The agent walks A → B → C each episode; reaching C gives +10 and ends the episode.

  • Episode 1: A→B (reward 0): Q(A, right) = 0 + 0.5 × [0 + 0.9×0 − 0] = 0. B→C (reward 10): Q(B, right) = 0 + 0.5 × [10 + 0 − 0] = 5.
  • Episode 2: A→B: Q(A, right) = 0 + 0.5 × [0 + 0.9×5 − 0] = 0.5 × 4.5 = 2.25. B→C: Q(B, right) = 5 + 0.5 × [10 − 5] = 7.5.

The reward information spreads backward: B learns it is good first (next to the goal), then A learns moving toward B is good, because A's update uses the best Q of the next state (B), which is 0 until B learns. Analogy: a rumour spreading backward: C is great, B hears first, then A. Because Q(B, right) > Q(B, left) the agent chooses "right". Check: Q(B, right) = 5, reward 10, episode ends: 5 + 0.5 × (10 − 5) = 7.5.

6. Policy gradients: learning with a neural network (peer notes, following the StatQuest video)

Problem with ordinary backpropagation (Lesson 6): it needs the correct answer to compute the error and the slopes, but in RL we usually do not know the correct action; we find out later through a reward. Policy gradients fix this: take a guess to calculate the derivative, use a reward to update that derivative, then update the parameter with the updated derivative.

The fries story

A small network decides where to go for fries: Norm's (big portion) or Squatch's (small portion). Input: hunger (0 = not hungry, 1 = very hungry). Outputs: P(Norm's) and P(Squatch's), adding to 1. If you are not hungry the small portion is the right choice. Step by step at hunger = 0.0:

  1. Decide: the network gives P(Norm's) = 0.5, P(Squatch's) = 0.5. A random number (0.2) falls in the first half, so we go to Squatch's.
  2. Guess: assume that was the right choice; the ideal would be P(Squatch's) = 1.0.
  3. Derivative: from the gap between ideal (1.0) and actual (0.5): size 0.5 for the bias being trained.
  4. Reward: we get a small portion while not hungry: the guess was correct, reward = +1.0 (a big portion would mean the guess was wrong, reward −1.0).
  5. Update the derivative with the reward: 0.5 × 1.0 = 0.5.
  6. Gradient descent step with learning rate 1.0: step size = 1.0 × 0.5 = 0.5.
  • A positive reward keeps the derivative's direction: the guessed action becomes more likely.
  • A negative reward flips the sign: the update pushes the other way, making the guessed action less likely (derivative 0.5, reward −1.0, learning rate 1.0: updated derivative −0.5, step −0.5).
  • The size of the reward scales the step (other reward values than ±1 are possible). Sign conventions differ between textbooks; the idea is what matters.

Analogy: a coach's whistle: the coach cannot name the perfect move but gives a thumbs up (+1) or down (−1); up makes you repeat it, down makes you do it less. Summary: use the network to decide, get the actual reward, multiply the derivative by the reward, apply gradient descent.

Written questions

W1. Define reinforcement learning and contrast it with supervised and unsupervised learning. Give two real examples.

RL: an agent learns by interacting with an environment and receiving feedback as rewards (+) or penalties (−). Supervised learning has correct answers (teacher), unsupervised has no answers (find groups), RL has only a reward or penalty after it acts, which may come later. Examples: a puppy trained with treats; Boston Dynamics robots learning movements; game-playing programs; chatbots tuned with human-feedback rewards.

W2. Define agent, environment, state, action, reward, policy and episode, and explain pi(s, ai) = Pi with an example.

Agent: the learner that acts; environment: everything it interacts with; state s: current situation; action a: what it does; reward r: feedback number after an action; policy π: rule for choosing actions; episode: one full try from start to end. π(s, ai) = Pi means in state s the policy chooses action ai with probability Pi, and the probabilities for the state add to 1. Example: π(s1, lift leg) = 0.7, π(s1, turn) = 0.2, π(s1, wait) = 0.1.

W3. Explain the return and discount factor. In the corridor A-B-C with +10 at C, compute G for rewards 0, 0, 10 with γ = 0.9 and 0.5, and V(A) and V(B) for γ = 0.9.

Return G = r1 + γr2 + γ²r3 + …, the total reward over time, with later rewards worth less (γ between 0 and 1; near 1 patient, near 0 short-sighted). γ = 0.9: 0.81 × 10 = 8.1; γ = 0.5: 0.25 × 10 = 2.5. Under always-go-right: V(B) = 10, V(A) = 0.9 × 10 = 9.

W4. Explain exploration vs exploitation and compute the ε-greedy probabilities for ε = 0.3 and three actions.

Exploit: use the action that has worked best; explore: try something different that may be better. ε-greedy explores with probability ε (random action) and exploits otherwise. With ε = 0.3 and 3 actions, exploration gives 0.3/3 = 0.1 to each action; the best action gets 0.7 + 0.1 = 0.8; the others 0.1 each (total 1.0). Often ε starts large and shrinks.

W5. State the Q-learning update and perform the first two episodes in the corridor (α = 0.5, γ = 0.9, Q = 0 initially, +10 at C).

Q(s,a) ← Q(s,a) + α[r + γ max Q(s′,a′) − Q(s,a)]. Episode 1: Q(A,right) = 0 + 0.5[0 + 0 − 0] = 0; Q(B,right) = 0 + 0.5[10 − 0] = 5. Episode 2: Q(A,right) = 0 + 0.5[0 + 0.9×5 − 0] = 2.25; Q(B,right) = 5 + 0.5[10 − 5] = 7.5. Reward information spreads backward from the goal toward the true values 10 and 9.

W6. Explain policy gradients using the fries story.

Ordinary backpropagation needs the correct answer, which RL lacks. Policy gradients: use the network to decide (hunger 0: P(Norm's) = P(Squatch's) = 0.5; a random number 0.2 picks Squatch's); guess that this was right and compute the derivative (0.5); get the reward from the environment (small portion when not hungry: +1.0); multiply the derivative by the reward (0.5); take a gradient-descent step (learning rate 1.0 × 0.5 = 0.5). A positive reward makes the guessed action more likely; a negative reward flips the sign and makes it less likely.

W7. Explain reward hacking and two other practical problems of RL.

Reward hacking: the agent finds a cheat that earns reward without doing what was meant (a cleaning robot rewarded for no visible dirt hides dirt under a rug), so the reward must match the real goal. Other problems: lots of trial and error (millions of tries; costly or risky in the real world), safe exploration (random actions can cause harm), delayed reward and credit assignment, and policies that are hard to explain.
