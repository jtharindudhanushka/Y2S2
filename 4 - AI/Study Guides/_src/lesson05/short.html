Short note: revision sheet

TopicRemember
MLBranch of AI where a system learns patterns from data to predict, decide or generate. Pattern = model. Jobs: regression, classification, forecasting, optimisation.
3 typesSupervised (labelled; teacher) · Unsupervised (no labels; clustering, association rules) · Reinforcement (agent, rewards / penalties).
Supervised kindsClassification (category; binary / multiclass) · regression (number) · time series (trend, seasonality, lag).
Data wordsRecord = row; feature = input column (attribute = dimension); label = answer; sample vs population; noise.
Donor exampleModel 1 classification (will give?), model 2 regression (how much?). Expected value = Σ P·D (0.70×1200 = 840; minus cost 10 = 830). Phone 10 /-, letter 25 /-. GA chromosome 11011 = 1420.
PreprocessingFeature engineering (age from DOB; BMI), feature selection (drop ID), Z-score = (x − mean) / SD (80 in 40..80: 1.41).
Association rulesSupport = how common the combination (4/10 = 40 %); confidence = how reliable the rule (4/5 = 80 %).
Curse of dimensionalitySparse data; distances lose meaning; overfitting + heavy compute. Fix: PCA / autoencoder (dimensionality reduction).
Train / test80 % / 20 %. Underfit = high bias (high train + test error); overfit = high variance (train ~0, test high). Find the right complexity.
ScoresAccuracy (TP+TN)/all; precision TP/(TP+FP); recall TP/(TP+FN); specificity TN/(TN+FP). Cross-validation: k folds, average.
Linear regressionŷ = w x + b (b = bias, w = slope). Multiple: Σ Wixi with x0 = 1. Fit = choose w, b.
Errorε = y − ŷ; SSE = Σ(y − ŷ)² = f(w, b); minimise it (least squares). R² = (SSE_mean − SSE_line) / SSE_mean.
Gradient descentnew w = old w − η × slope. Big η overshoots; small η is slow. Error bowl is convex.
Logistic regressionz = wx + b; ŷ = 1/(1+e−z) in (0,1); threshold 0.5; boundary at z = 0 (hyperplane). Classification, not regression. Best fit: maximum likelihood / small error.
Linear vs logisticNumber vs probability/category; least squares vs maximum likelihood.
Exam tipBe able to compute SSE for a line, do one gradient-descent update, compute sigmoid and predict a class, and compute accuracy / precision / recall from a confusion matrix.
