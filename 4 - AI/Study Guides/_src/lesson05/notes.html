1. What is machine learning?

DefinitionMachine learning (ML) is a branch of AI in which a computer system learns patterns from data and uses those patterns to make predictions, decisions or generate outputs, rather than following hand-written rules. The pattern it learns is a model.

Analogy: learning to spot a ripe mango. Nobody gives a rule book; after many mangoes you judge a new one. ML sits beside genetic algorithms, swarm intelligence and fuzzy logic inside AI (Lesson 1).

Predictive MLGenerative ML
Predicts an outcome from given information: future values, exam marks.Generates new content or sequences from learned patterns: predicting the next word repeatedly to write text.

Caution (lecturer's shorthand): "supervised ML is mostly predictive; unsupervised is generative; generative ML = unsupervised ML + supervised fine-tuning + reinforcement learning". Supervised/unsupervised describe how a machine learns; predictive/generative describe what it produces. They overlap but are not the same.

2. Three ways to learn

  • Supervised: thousands of examples with input and right answer; the model learns the relationship to predict answers for new data. Splits into classification (a category), regression (a number) and time-series prediction (a value from a sequence over time).
  • Unsupervised: data with no answers; the machine finds structure. Two main kinds: clustering and association rule mining.
  • Reinforcement: an agent acts in an environment, getting rewards for good actions and penalties for mistakes, and updates its strategy to collect the most reward (Lesson 10; Boston Dynamics robots learn movements this way).

Quick test: correct answers present → supervised; just finding groups → unsupervised; an agent acting and getting rewards → reinforcement.

4. Supervised learning in detail

KindAnswerNotes and examples
Classificationa categoryModel draws decision boundaries between classes. Binary (two classes, 1/0: donate or not) or multiclass (three or more: class 1–4). Spam vs inbox; fracture on an X-ray. A decision tree is one method.
Regressiona number on a smooth scaleFit a line or curve through past points. House price, exam marks, tomorrow's temperature.
Time seriesa future valueOrder is the main predictor (unlike ordinary regression with independent points). Tracks trend, seasonality (weekly / monthly cycles) and lag (yesterday affects today). Electricity demand, monthly inventory.

Forecasting example. Sales on days 1–5: 300, 310, 312, 320, 325. Trend method: daily changes 10, 2, 8, 5, average 6.25, so day 6 ≈ 325 + 6.25 = 331.25. Average of the last 3 days: (312 + 320 + 325)/3 = 319 (lower, because an average of old values lags behind a rising trend). ML can learn it with lag features (yesterday's sales as input, today's as the answer).

Donor 2: 0.60 × 500 = 300; minus 25 letter = 275. Donor 3: 0 − 10 = −10 (a loss: skip). Contact a person only if the expected value beats the cost.

With expected incomes 840, 300, 0, 200, 120 and a cost of 10 each: 11011 gives income 1460, cost 40, profit 1420; 11111 gives profit 1410, so 11011 wins. (Multi-objective optimisation chases two or more goals at once, e.g. minimise cost and CO2 emissions.)

5. Preparing the data

Data preprocessing (like washing and chopping before cooking): Feature engineering makes better features (date of birth → age; BMI = weight / height²: 60 kg and 1.5 m gives 60/2.25 = 26.7). Feature selection drops useless columns (student ID does not help predict marks): faster model, less noise, fewer dimensions.

Z-scorez = (x − mean) / standard deviation: how many standard deviations a value is from the average. It puts features of very different sizes on one scale (salary vs age).

Marks 40, 50, 60, 70, 80: mean = 60; squared differences 400, 100, 0, 100, 400 sum 1000; /5 = 200; standard deviation = √200 ≈ 14.14. For 80: z = 20/14.14 = 1.41; for 60: 0; for 40: −1.41.

6. Unsupervised learning

  • Clustering: group similar items by their distance, without labels (students gather in friend groups). Example: shoppers into bargain hunters, weekend casuals, luxury buyers. The machine finds the groups; humans name them. In student data (height, weight, Z-score, GPA...), plotting only height and weight may show 2 clusters (guess: two groups of students); adding a third feature (the Z-score) can make the old clusters disappear and new ones form.
  • Association rule mining: find "if this, then that" among items that occur together. 10 baskets: 5 contain patties and buns; 4 of those also contain ketchup. Support = 4/10 = 40 % (how common the combination is); confidence = 4/5 = 80 % (how reliable the rule is). Rule: patties + buns → ketchup. A shop can place ketchup near the buns.

7. Too many features: dimensions and PCA

Attribute = feature = dimension = column. 1 feature = a line, 2 = a page, 3 = a box, hundreds = a space we cannot picture (a medical record with 200 metrics is a point in 200 dimensions; a 1,000-pixel image is a point in 1,000 dimensions). More dimensions create the curse of dimensionality:

ProblemExplanation
1. Data becomes sparseWith 10 levels per feature and 100 points: 1 feature = 10 boxes (10 points each); 2 features = 100 boxes (1 each); 3 = 1,000 (0.1 each); 50 features = 1050 boxes (almost 0). Points end up lost in a huge empty space.
2. Distances lose meaningIn very high dimensions almost every pair of points is about equally far apart, so clustering and classification cannot tell what is similar.
3. Overfitting and heavy computingHundreds of variables need lots of computing and let the model mistake noise for a pattern.

Fix: dimensionality reduction. PCA (Principal Component Analysis) builds a few new features that keep most of the variation (spread) in the data. Example: four students (150,45), (160,52), (170,60), (180,68): taller means heavier, so the points lie almost on one line and one number ("overall body size", the first principal component PC1) describes them almost as well as two. If PC1 holds 95 % of the variation, keeping only it halves the columns with little loss. An autoencoder is a small neural network that squeezes data into a short code and rebuilds the original from it.

8. Training, testing, bias and variance

We cannot measure the whole population, so we build a model from a sample. A model trained too closely on one sample may perform badly on other samples: the bias–variance problem (the model is overfitted to that sample). So we split the data, about 80 % training and 20 % testing (1,000 records → 800 and 200). Training data = practice papers; testing data = the real exam.

UnderfittingGood fitOverfitting
Also calledHigh biasBalancedHigh variance
ModelToo simple (a straight line on a curve): rigid wrong assumptionsFollows the broad pattern, ignores noiseToo flexible (zig-zag through every dot): memorises noise; would change a lot with another sample
Training errorHighLowAlmost zero
Testing errorHighLowHigh

Example errors (training / testing): straight line 10 / 12 (underfit), balanced curve 4 / 5 (good), squiggle 0 / 20 (overfit). Always compare the two: a big gap warns of overfitting. Diagnosis drill: 12 / 13 → underfitting; 1 / 15 → overfitting. Finding the right model complexity is the bias–variance problem: more complexity lowers bias but raises variance. ("All models are wrong. Some are useful.")

Cross-validation: one 80/20 split can be lucky or unlucky, so cut the data into folds (e.g. 5); each round trains on 4 and tests on the left-out 1, so every part is the test part once; average the scores (80, 84, 78, 86, 82 → 410/5 = 82).

The ML workflow: define the problem → collect data → prepare data → split → train → test → improve (high errors = too simple; good training but bad testing = overfitting: more data, simpler model, other method) → use.

10. Linear regression

For predicting a number, linear regression finds the best straight line (or flat plane) through the data: curve fitting, finding a function that matches input to output. Analogy: a ruler laid on a scatter plot as close to all the dots as possible.

ŷ = w · x + bx = input; w (weight; also m or W1) = slope: how strongly x affects the prediction; b (bias; also c or W0) = value when x = 0, sliding the line up or down; ŷ ("y-hat", hat = predicted) = prediction; y (no hat) = the real answer.

w = 0.8, b = 1.2: for x = 2, ŷ = 1.6 + 1.2 = 2.8; for x = 5, ŷ = 5.2. Fitting means choosing w and b; there are infinitely many lines. Simple regression has one feature (ŷ = W1x1 + W0); multiple has two or more (ŷ = W0 + W1x1 + W2x2...), fitting a plane. Example: ŷ = 20 + 5×hours + 0.3×attendance for 4 hours and 90 %: 20 + 20 + 27 = 67. x0 = 1 trick: ŷ = Σ Wixi with x0 = 1 treats the bias like any other weight (used in neural networks). Feature engineering and feature selection are the data preprocessing methods used before fitting.

How good is a line? Error, SSE and R²

  • Error (residual) of one point: ε = y − ŷ.
  • Square it so errors do not cancel (+5 and −5 would add to 0; squared gives 50) and so big misses are punished (2 → 4, 10 → 100).
  • SSE = Σ (y − ŷ)², the Sum of Squared Errors; the best line has the smallest SSE (least squares).

Rotating the line (least squares idea): for data (1,2), (2,3), (3,5), (4,4), (5,6) (means x = 3, y = 4) keeping the line through (3, 4): slope 0 → SSE 10; 0.5 → 3.5; 0.9 → 1.9; 1.2 → 2.8. SSE falls then rises: the best is near slope 0.9, the least-squares line ŷ = 1.3 + 0.9x. R² = (SSE around the mean − SSE around the line) / SSE around the mean = (10 − 1.9)/10 = 0.81: the line explains 81 % of the variation (near 1 = very good; near 0 = no better than guessing the average).

The error depends only on w and b (the data are fixed facts): E = f(w, b). Plot E for every (w, b) and you get a bowl; the best line is at its bottom. Different (W0, W1) give different errors: ML = finding the parameter values that minimise E. With two features E = f(W0, W1, W2). An ML-style line search was also introduced in Lesson 4 (searching for the best m, c).

Gradient descent: rolling down the bowl

We cannot try every (w, b), so we start with a guess and keep stepping downhill (walking down a hill in fog): find the slope (gradient) of the error, step the opposite way, repeat until steps are tiny.

new w = old w − η × slopeη (eta, learning rate; also α) is the step-size multiplier you choose. Plotting E against w typically gives a convex curve, so there is one bottom.

Slope of a curve at a point = steepness of a tiny straight piece touching it (e.g. at w = 0: slope ≈ −6). Learning rate:

ηBehaviour
Just right (0.1)Steady steps toward 3.
Too big (1.1)Large jumps: faster but risk overshooting: w = 0, 6.6, −1.32, 8.18 ... jumps past the bottom and gets worse.
Too small (0.001)Small jumps: more precise but converges very slowly (first step only 0.006).

On a real line both slopes are used: slope for b = −2Σ(y − ŷ); slope for w = −2Σx(y − ŷ). Data (1,2), (2,4), (3,6), start w = b = 0, η = 0.01: errors 2, 4, 6, SSE 56; slope b = −24; slope w = −56; new b = 0.24, new w = 0.56; new predictions 0.80, 1.36, 1.92; new SSE ≈ 25.06. One step cut the error from 56 to 25.06; the best line is ŷ = 2x (SSE 0). Training is often described as repeated passes of this update; in neural networks the same idea is called back-propagation (Lesson 6).

11. Logistic regression

Despite the name, logistic regression is a classification method: it predicts the probability that an input belongs to a class (Pass/Fail, Spam/Not spam). Why not a straight line? A line is unbounded (−1.5 or +3.2) but a probability must stay between 0 and 1, and one far-away point can tilt the whole line. Instead: compute z = w·x + b, then squash it with the sigmoid:

ŷ = σ(z) = 1 / (1 + e−z)Output always between 0 and 1. (e ≈ 2.718 is Euler's number, not the error.)

With SSE on the sigmoid output, (w = 1, b = −3.5) gives E = 0.221 while (w = 0.2, b = 0) gives 1.204, so the first is better; gradient descent starts from a poor guess and steps down toward it. Alternatively maximum likelihood: multiply, over all data, the curve's probability for what actually happened (obese mouse: curve height; non-obese: 1 − height); the curve with the highest product wins. Mice obese / not / obese: curve A (0.9, 0.2, 0.7) gives 0.9×0.8×0.7 = 0.504; curve B (0.6, 0.5, 0.5) gives 0.15, so A is better.

Several inputs: Model A (linear): ŷ = W1x1 + W2x2 + W0 = Σ Wixi (x0 = 1). Model B (logistic): ŷ = 1 / (1 + e−Σ Wixi), i.e. Model A pushed through a sigmoid. Neural networks are good for both numerical and categorical data (Lesson 6: a single sigmoid neuron is logistic regression).

Key takeaways ML learns patterns from data: supervised (answers given: classification, regression, time series), unsupervised (clustering, association rules) and reinforcement (rewards). Prepare data (feature engineering and selection, Z-score) and beware too many dimensions (PCA). Split train / test (80 / 20); underfit = high bias, overfit = high variance; judge with accuracy, precision, recall and cross-validation. Linear regression ŷ = wx + b minimises SSE (least squares) using gradient descent, new w = old w − η × slope. Logistic regression squashes z through a sigmoid and thresholds at 0.5.
