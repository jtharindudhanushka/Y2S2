Short note: revision sheet

TopicRemember
SequencesOrder matters; need memory. Lag table: slide a window, next value = answer (25,28,23,31,26 window 2). Never shuffle time (data leakage); train on past, test on future.
RNNFeedback loop; one input at a time; same weights at every step (unrolling adds no weights). new memory = f(winx + wloop×old + b). Example: 0.5, 1, 0.5 → 0.5, 1.25, 1.125.
Vanishing / explodingValue after n steps = wn. w > 1 explodes (250 ≈ 1015), w < 1 vanishes (0.550 ≈ 10−15). Step = η × gradient: huge jumps or no learning.
LSTMLong-term lane (no weights; × percentage, + new) and short-term memory. Sigmoid = percentage gate (0..1); tanh = potential memory (−1..1). 1 forget (keep %), 2 input (add), 3 output (new short-term).
LSTM numbersLT 2.0, ST 0.5, in 1.0: forget σ(0.75) = 0.679 → 1.358; add 0.905 × 0.623 = 0.563 → LT 1.922; ST = tanh(1.922) × σ(1) = 0.958 × 0.731 = 0.700.
Vision tasksClassification (one label), object detection (labels + bounding boxes), generation (new pixels: Stable Diffusion, VAE, GAN).
Image dataGrid of numbers; grayscale 1 channel; RGB 3 channels; tensor (H × W × C); 128×128×3 = 49,152.
Dense NN failsDestroys spatial geometry; parameter explosion (49,152 × 100 = 4,915,200); no shift invariance. CNN: 3×3×3 filter = 27 weights + 1 bias.
CNN aimsReduce input nodes; tolerate small shifts; exploit correlations.
ConvolutionFilter (kernel) slides over image; dot product of patch and filter + bias → feature map. Slide example: dot product 3, bias −2, cell = 1.
Output sizefloor((N + 2P − K)/S) + 1: 6, K 3, S 1, P 0 → 4; 5, 3, S 2, P 1 → 3.
WeightsK × K × in-channels × out-channels + out-channels biases (8 filters 3×3 on RGB = 216 + 8 = 224).
ReLU / poolingReLU: negatives → 0. Max pooling: maximum of each 2×2 window (4×4 → 2×2); no weights; partial shift tolerance. Then flatten → dense → softmax (2,1,0 → 0.665, 0.245, 0.090).
Slide networkO pooled 1,0,0,1: sum + 0.97 = 0.34 → O 1.00, X 0.00. X pooled 0,1,1,0: 1.10 → O −0.01, X 1.01.
CNN code (32×32×3)conv(3→32) 30×30, pool 15; conv(32→64) 13, pool 6; conv(64→128) 4, pool 2; flatten 512; linear 128; linear 10. About 160,202 parameters.
U-Net colouringLab: L = lightness (input), a, b = colour (output); 128×128; MSE; 15–20 epochs; encoder, decoder, skip connections carry detail; plausible not true colours.
Exam tipBe ready to unroll an RNN for 2–3 steps, show wn exploding or vanishing, do the three LSTM stages with given gate values, and do a convolution, ReLU and max pool on a small grid (with output-size and weight counts).
