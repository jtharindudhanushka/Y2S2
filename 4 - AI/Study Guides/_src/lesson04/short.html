Short note: revision sheet

TopicRemember
AI searchFinding a sequence of actions from an initial state to a goal state. Uses: problem solving, games, route planning, optimisation.
3 aimsFind a solution · find all solutions · find the best solution.
State space problemInitial state · operators · state space (all reachable states) · goal test. Answer = the path. Identical contents = same state.
Classical vs ML spaceDiscrete (stairs, operators) vs continuous (ramp, gradient descent, goal = low-error region).
Uninformed = blindAlso exhaustive / brute force. Knows only operators and goal test: BFS, DFS.
BFSLevel by level; queue; visited list; complete; optimal (equal costs); O(bd); memory heavy.
DFSOne branch deep, backtrack; stack / recursion; not complete; not optimal; O(bm) time; O(b·m) space.
Two jugs (3L, 4L) goal 2LState (x,y). 6 operators: fill 3L / 4L, empty 3L / 4L, pour 3→4, pour 4→3. Path (0,0)→(3,0)→(0,3)→(3,3)→(2,4)→(2,0): 5 steps. 11 of 20 states generated.
Why not LPWorld not linear; discrete states; answer is a sequence; logical constraints; graphical method only 2–3 variables; non-convex spaces.
Heuristic h(n)Estimate of closeness to the goal; an estimate, not a guarantee.
UCSExpand smallest g(n); lowest-cost path; uninformed.
Greedy best-firstExpand smallest h(n); fast, not guaranteed best (found 7 vs 6).
A*f = g + h; optimal if h is admissible (never overestimates). Example map: S, A, B, G cost 6.
TSPVisit each city once and return; (n−1)! routes; NP-hard (9! = 362,880; 19! about 1.2×1017).
KnapsackMax total value within a weight limit (limit 5: A+B = value 7).
Exam tipBe able to run BFS/DFS on a small tree (show queue/stack), run A* with a g, h, f table, and set up a state space (state, operators, goal test) for a puzzle.
