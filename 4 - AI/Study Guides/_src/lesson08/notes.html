3. Generation is repeated next-word prediction (from the course)

Peer notes: "ChatGPT writes text one word at a time"; lecturer: generative ML = next word prediction in a sequence. The model reads everything written so far, predicts the next word, adds it, and repeats.

Why this needs memory of the sequence: "I grew up in France, so I speak fluent ___" needs the word "France" from far back (Lesson 7). That is the job of sequence models.

Why RNNs and LSTMs were not enough (links Lessons 7 and 8)

  • An RNN reads one input at a time, passing memory down a chain: slow (cannot process all steps at once) and the gradient vanishes or explodes over long chains (wn).
  • An LSTM protects a long-term lane with gates and remembers longer, but still works step by step along the chain.
  • The transformer's answer (background, section 4): let every word look directly at every other word in one step, so long-range links ("France" → "French") do not have to travel along a chain.

4. Background: tokens, embeddings and self-attention (not from your course materials)

BackgroundThe next two sections are standard introductory transformer material, not from the lecture slides. They are here so you understand the "reads all words together and decides which matter" sentence above.

Tokens and embeddings

  • Token: the piece of text the model works with: a word or part of a word (e.g. "unhappy" → "un" + "happy"). The model's vocabulary is the set of all tokens it knows.
  • Embedding: each token is turned into a list of numbers (a vector) so that tokens with similar meaning get similar numbers. These vectors are learned during training, like weights.
  • Positional information: because all words are read together, the model must be told each word's position (word order matters: "dog bites man" ≠ "man bites dog"); a position signal is added to each embedding.
  • Context window: the maximum number of tokens the model can look at at once (this is why Lesson 2's context engineering limits how much you can put in a prompt).

Self-attention in one picture

For each word, self-attention asks "which other words should I pay attention to, and how much?", then builds a new representation of that word as a weighted mix of all the words. In the standard recipe every token makes a query (what am I looking for?), a key (what do I contain?) and a value (what I pass on). Scores = query · key (dot product), divided by √(vector size), turned into weights that add to 1 with softmax (Lesson 6's softmax idea), then the output is the weighted sum of the values.

Attention(Q, K, V) = softmax( Q KT / √d ) Vscores → softmax → weights add to 1 → weighted sum of the values.

Worked example (tiny, to show the arithmetic)

Three tokens with 2-number embeddings: A = (1, 0), B = (0, 1), C = (1, 1). To keep it simple use Q = K = V = the embeddings (a real model learns separate matrices). Take token C as the one looking around: scores with A, B, C = (1, 1, 2) / √2 = 0.707, 0.707, 1.414. Softmax: e0.707 = 2.03, e0.707 = 2.03, e1.414 = 4.11, total 8.17, so weights 0.248, 0.248, 0.503 (they add to 1). New C = 0.248 × (1, 0) + 0.248 × (0, 1) + 0.503 × (1, 1) = (0.752, 0.752): mostly C itself, with some of A and B mixed in.

Every token does this at once, which is why transformers train quickly on modern hardware. Multi-head attention runs several attentions in parallel, each free to focus on a different relationship (grammar, meaning, position), and joins the results.

5. Background: the transformer block and how a model answers

  • Block: self-attention (mix information between tokens) → feed-forward network (an ordinary neural network applied to each token; Lesson 6) → with "add & normalise" shortcuts around each part. Stack many blocks (dozens) and the model can build up meaning layer by layer, like a CNN builds shapes from edges.
  • Output: the last layer gives a score for every token in the vocabulary; softmax turns the scores into probabilities and the model picks (or samples) the next token. Illustrative scores 2, 1, 0.5, 0 for "mat / floor / sofa / roof" give probabilities 0.58, 0.21, 0.13, 0.08. A higher temperature flattens these (more varied text); a lower one sharpens them (more predictable).
  • Two common shapes: encoder models (read a whole text and understand it, e.g. for classification) and decoder models (generate text token by token, e.g. ChatGPT-style assistants); the original design had both an encoder and a decoder (e.g. for translation).
  • "Large language model" (LLM): a very large transformer (billions of weights) trained on huge amounts of text. Your EU AI Act notes call such flexible models general-purpose AI (GPAI) models.
  • Hallucination: because it only predicts a likely next token, an LLM can state false things confidently; this is why the Kitchen Guide's context engineering / RAG (Retrieval-Augmented Generation) feeds it the exact facts so it does not guess (Lessons 1 and 2).

6. How a generative model is trained (from the course: the three ingredients)

Your notes: generative ML = unsupervised ML + supervised fine-tuning + reinforcement learning. Spelling out the three ingredients with the Lesson 5 vocabulary:

StageLearning type (Lesson 5)What happens (background detail in italics)
1. Learn the patterns of language / imagesUnsupervised (no labels given)The model reads huge amounts of unlabelled data and learns structure. For text, the data labels itself: the "answer" is simply the next word.
2. Fine-tuneSupervised (labelled examples)Show it examples of good question → answer pairs so it learns to follow instructions.
3. Improve with feedbackReinforcement learning (agent, reward, penalty)Responses are scored (rewarded for helpful / safe, penalised otherwise) and the model adjusts to collect more reward (Lesson 10).

The weights in all stages are still learned by the same machinery as Lesson 6: forward pass, loss, backpropagation, gradient descent, many epochs.

Key takeaways Discriminative AI classifies or predicts; generative AI creates new content, typically by predicting the next word again and again. Transformers (inside deep learning) read all words together and let each word attend to the others, avoiding the chain and vanishing-gradient limits of RNNs and LSTMs; they power LLMs such as ChatGPT. A generative model is trained with unsupervised learning, then supervised fine-tuning, then reinforcement learning. (Attention, tokens and the block details are background, not from your slides.)
