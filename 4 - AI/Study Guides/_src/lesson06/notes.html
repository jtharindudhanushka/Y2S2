Learning outcomes

  • Explain what a neural network is and why a straight line is not enough (the drug-dose "squiggle")

  • Know the activation functions (linear, sigmoid, tanh, ReLU, SoftPlus), their ranges, uses and weaknesses

1. The big idea: a squiggle-fitting machine

DefinitionAn artificial neural network (ANN) is a network of simple processing units called neurons (nodes) wired together in layers, loosely inspired by the brain. Together they can fit curvy, non-linear patterns that a straight line cannot.

Link to Lesson 5: logistic regression is simply a neural network with one neuron: inputs, a weighted sum plus bias, then a sigmoid giving a probability. A neural network duplicates that building block many times and arranges the neurons in layers.

The problem a straight line cannot solve. A drug is tested at three doses:

DoseEffective?Value
LowNo0
MediumYes1
HighNo (too much)0

The pattern 0, 1, 0 rises then falls like a hill. A straight line (linear regression) can only go up or down, so it cannot follow a hill. Analogy: a ruler cannot trace a hill, but bendy wires can be stretched, flipped and joined into almost any shape. Each neuron makes one bendy wire; the network joins them into a squiggle.

2. Inside one neuron: two steps

  1. Aggregation (weighted sum): z = w1x1 + w2x2 + … + b = Σ wixi + b. Each input has its own weight (amplifies or suppresses it); the bias is a baseline offset. In Lesson 5 notation the bias is a weight W0 on a fixed input x0 = 1, so z = Σ Wixi.
  2. Activation: a = f(z). The activation function decides how strongly the neuron "fires" to the next layer. Analogy: deciding about a party: friends' opinions (inputs) count more or less (weights); add your mood (bias) to get z; then decide how excited to feel (activation).

With one input it is simply z = w x + b, the same line as linear regression. A neuron with a linear activation is linear regression (c = W0, m = W1); a neuron with a sigmoid activation is logistic regression.

Worked example

Inputs x1 = 2, x2 = 3; weights w1 = 0.5, w2 = −1; bias b = 1. Then z = (0.5 × 2) + (−1 × 3) + 1 = 1 − 3 + 1 = −1.

Real neurons obey the all-or-none law (fire completely or not at all); activation functions are a smoother mathematical version of this.

3. Building the squiggle (the drug network)

Network: 1 input (dose, scaled 0 to 1), 2 hidden nodes, 1 output. Both hidden nodes use the SoftPlus curve f(x) = ln(1 + ex) (a smooth ReLU: almost 0 for negative x, then rising), but with different weights and biases, so they make differently shaped curves. The network scales and flips them, adds them and adds a bias.

4. Activation functions

Why we need them: layers would collapse

If layer 1 is z1 = 2x + 1 and layer 2 is z2 = 3z1 − 2, then z2 = 3(2x + 1) − 2 = 6x + 1: two layers became one straight line (check x = 2: 3 × 5 − 2 = 13 = 6 × 2 + 1). A network of only straight-line steps is still a straight line however deep. An activation function bends the signal and prevents this.

  • Linear: what goes in comes out. Use: output layer for regression (house price, temperature). Limit: in hidden layers it makes layers collapse into one line.
  • Sigmoid: squashes to 0 to 1 (big positive → 1, big negative → 0, 0 → 0.5). Use: output layer for binary classification (a probability: 0.88 = 88 % chance). Limits: vanishing gradient (flat at the extremes; the slope is σ(1 − σ): 0.25 at z = 0, 0.105 at z = 2, 0.0066 at z = 5, so gradient descent takes tiny steps and early layers almost stop learning) and not zero-centred (all outputs positive, so weight updates zig-zag).
  • Tanh: a scaled, shifted sigmoid with range −1 to +1 through (0, 0). Advantage: zero-centred, which balances updates and speeds training. Limit: still flattens at the extremes (vanishing gradient).
  • ReLU: a one-way valve: z ≤ 0 gives 0, z > 0 gives z. Why it dominates modern deep learning: cheap (an if-check, no exponentials), no flat part for positives (slope exactly 1, so gradients do not vanish) and sparse (negatives become 0 so many neurons stay quiet). Limit: dying ReLU: if a neuron's input is always negative it outputs 0 with slope 0 and stops learning for good.
  • SoftPlus: a smooth ReLU with no sharp corner (used in the drug network).

5. How a network learns

A network does not start out smart; it learns by trial, error and repetition. Analogy: practising with past papers: attempt a paper (forward pass), get your marks (loss), work out which misunderstanding lost each mark (backpropagation), restudy those parts (update the weights). Doing the whole pile once is one epoch.

  1. Start with small random weights and biases.
  2. Forward pass: send data from input to output to get predictions.
  3. Loss: measure the error with a loss function (sum of squared residuals, SSR = SSE from Lesson 5).
  4. Backpropagation: work backward to find the slope of the loss for every weight and bias (each weight's share of the error), using the chain rule.
  5. Gradient descent: new value = old value − learning rate × slope.

Backpropagation finds the slopes; gradient descent uses them to update.

Chain rule in plain words: if A changes B and B changes C, then A changes C by (A→B) × (B→C). 1 hour of work earns 10 dollars, 1 dollar buys 3 sweets, so 1 hour buys 10 × 3 = 30 sweets.

Weight update written another way (Geethma's notes): Wnew = Wold + ΔW, with ΔW = −η · dE/dW (her sheet writes ΔW = η · dE/dW with the minus sign hidden in the slope). Either way weights move to lower the error.

Worked example A: optimise only the last bias b3

Drug network, data: dose 0 → 0, 0.5 → 1, 1 → 0. Keep everything fixed except the final bias. Before b3 is added the predictions are 0.569, 1.615, 0.585. Adding b3 raises each prediction one-for-one, so by the chain rule slope = Σ −2 × (observed − predicted) × 1. Learning rate 0.1, start b3 = 0:

Worked example B: one learning step on one neuron

One sigmoid neuron, inputs x1 = x2 = 1 and bias input x0 = 1, target y = 1, all weights start at 0, η = 1, error E = (y − ŷ)².

  • Forward: z = 0, ŷ = σ(0) = 0.5. Loss = (1 − 0.5)² = 0.25.
  • Slope for each weight = −2(y − ŷ) × ŷ(1 − ŷ) × x (three chain-rule parts: error vs ŷ, slope of the sigmoid, effect of the weight on z) = −2 × 0.5 × 0.25 × 1 = −0.25.
  • Update: new w = 0 − 1 × (−0.25) = 0.25 for every weight.
  • Check: new z = 0.75, ŷ = σ(0.75) = 0.679: moved from 0.5 towards 1.

Epochs

One epoch is one complete pass of the whole training set through the network, forward and backward. With 1,000 samples, seeing all 1,000 once is 1 epoch; training for 20 epochs is 20 passes. We need many because one pass cannot learn everything (like reading a textbook chapter several times).

6. Logic gates: AND, XOR and why we need hidden layers

A logic gate takes 0/1 inputs and gives a 0/1 output, so a neuron can be trained on its rows: z = w0 + w1x1 + w2x2, ŷ = f(z), error E = Σ(y − ŷ)² = f(w0, w1, w2), minimised by gradient descent.

All four match. The class 0 points (0,0), (0,1), (1,0) and the class 1 point (1,1) can be split by one straight line, so AND is linearly separable and a single neuron can learn it.

XOR: one neuron cannot

XOR means "exactly one input is 1". Class 1 points (0,1) and (1,0) sit on one diagonal of the square, class 0 points (0,0) and (1,1) on the other. No single straight line puts both class 1 points on one side and both class 0 points on the other, so XOR is not linearly separable and a single neuron (or basic logistic regression) cannot solve it. This was a famous problem in AI history; a trained network that does solve it gives outputs like 0.03, 0.97, 0.96, 0.04, rounding to 0, 1, 1, 0. Analogy: separating the two colours of a chess-board with one ruler: you need two cuts.

How a hidden layer solves XOR

XOR = (x1 OR x2) AND NOT (x1 AND x2). Use 2 hidden neurons (one for OR, one for AND) and an output neuron meaning "OR on, AND off". Example weights: hidden 1 (OR): a1 = σ(20x1 + 20x2 − 10); hidden 2 (AND): a2 = σ(20x1 + 20x2 − 30); output: σ(20a1 − 20a2 − 10).

Outputs 0, 1, 1, 0 = XOR. Check (1,1): a1 = σ(30) ≈ 1, a2 = σ(10) ≈ 1, z = 20 − 20 − 10 = −10, output σ(−10) ≈ 0. Each hidden neuron draws one straight boundary; the output neuron combines the two boundaries into a shape no single line can make. This is why more neurons become necessary.

7. Hidden layers and the Multi-Layer Perceptron (MLP)

DefinitionA hidden layer is a middle layer between input and output. A Multi-Layer Perceptron (MLP) is a neural network with an input layer, at least one hidden layer and an output layer. The drug network (1 input, 2 hidden, 1 output) is a small MLP.

For 2 inputs, 3 hidden neurons and 1 output: output z = a1w7 + a2w8 + a3w9 + bias, then ŷ = 1 / (1 + e−z).

Counting parameters: input→hidden 2 × 3 = 6 weights (w1–w6); hidden→output 3 × 1 = 3 weights (w7–w9); total 9 weights; biases 3 (hidden) + 1 (output) = 4; so 13 numbers are trained. Quick check: 2 inputs, 4 hidden, 1 output = 2×4 + 4×1 = 12 weights.

Worked forward pass

Input x = (1, 2); ReLU hidden layer, no hidden biases; hidden weights (for x1, x2): n1 = (0.5, −1), n2 = (1, 1), n3 = (−0.5, 0.5); output weights (1, 0.5, 2), output bias −1, sigmoid output.

  • Hidden 1: z = 0.5 − 2 = −1.5 → ReLU 0. Hidden 2: z = 1 + 2 = 3 → 3. Hidden 3: z = −0.5 + 1 = 0.5 → 0.5.
  • Output: z = 0 × 1 + 3 × 0.5 + 0.5 × 2 − 1 = 1.5; ŷ = σ(1.5) = 1 / (1 + 0.223) = 0.818 (about an 82 % chance of class 1).

What hidden neurons do

  • One neuron = one linear boundary; hidden neuron 1 makes boundary 1, hidden neuron 2 makes boundary 2, and the output neuron combines them. Hidden layers let a network solve XOR and fit squiggles.
  • Activation functions add the non-linear behaviour; without them all layers collapse into one line.
  • Neural networks work well with both numerical data (prices) and categorical data (Pass/Fail).

Simple models cannot fit every dataset

Data shaped like a bump cannot be followed by a straight line or a basic S-curve. A model too simple to capture the pattern underfits; one so complex that it memorises the training data and noise overfits. So use enough neurons to capture the pattern but not so many that it memorises (Lesson 5: bias–variance).

Key takeaways A neural network is many neurons in layers; each neuron computes z = Σ w x + b then a = f(z). Activation functions give curves (ReLU in hidden layers; linear or sigmoid at the output). Learning = forward pass, loss, backpropagation, gradient descent, over many epochs. One neuron can learn AND (linearly separable) but not XOR; a hidden layer (an MLP) solves XOR. Logistic regression is a one-neuron network.
