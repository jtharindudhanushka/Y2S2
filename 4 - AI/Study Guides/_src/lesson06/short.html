Short note: revision sheet

TopicRemember
ANNNetwork of simple neurons in layers (input, hidden, output). Fits squiggles a straight line cannot. Logistic regression = a one-neuron network.
NeuronStep 1 aggregation: z = Σ wixi + b. Step 2 activation: a = f(z). Weight = importance of an input; bias = baseline shift.
Brain parallelDendrites = inputs; synapse strength = weights; cell body = sum; axon hillock (threshold about −55 mV) = activation + bias; axon = output. All-or-none law.
Worked zx = (2, 3), w = (0.5, −1), b = 1: z = −1. Sigmoid 0.269; tanh −0.762; ReLU 0; SoftPlus 0.313.
Why activationsWithout them layers collapse into one straight line (2x+1 then 3z−2 = 6x+1).
Linearf(z) = z; (−∞, +∞); output layer for regression.
Sigmoid1/(1+e−z); (0, 1); output layer for binary classification; vanishing gradient, not zero-centred. Slope σ(1−σ): 0.25 at 0.
Tanh(−1, 1), zero-centred; still vanishing gradient.
ReLUmax(0, z); [0, ∞); cheap, no vanishing for z > 0, sparse; dying ReLU if always negative. Default for hidden layers. SoftPlus = smooth ReLU.
LearningRandom start → forward pass → loss (SSR) → backpropagation (chain rule gives each slope) → gradient descent: new = old − η × slope. Epoch = one full pass of the data.
Chain ruleA→B times B→C = A→C (10 dollars/hour × 3 sweets/dollar = 30 sweets/hour).
Neuron stepAll weights 0, x = 1,1,1, y = 1, η = 1: ŷ = 0.5, slope −0.25, new w = 0.25, new ŷ = 0.679.
ANDLinearly separable (one line); one neuron learns it (e.g. w = −6, 4, 4).
XORNot linearly separable; one neuron cannot. Needs a hidden layer: XOR = (OR) AND NOT (AND).
MLPInput + at least one hidden + output layer. 2-3-1: 6 + 3 = 9 weights, 3 + 1 = 4 biases, 13 numbers. 2-4-1: 12 weights. Forward-pass example gives ŷ = 0.818.
FitToo simple = underfit; too complex = overfit.
Exam tipBe ready to compute z and each activation output, do one gradient-descent update, explain why XOR needs a hidden layer, and count the weights and biases of an MLP.
