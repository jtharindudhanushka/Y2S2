TopicRemember
RLAgent learns by interacting with an environment; feedback = rewards (+) / penalties (−). No answer sheet; reward may come later. Examples: puppy, Boston Dynamics robots, games, chatbots (human-feedback rewards).
vs othersSupervised: correct answers; unsupervised: no answers; RL: only reward / penalty after acting.
LoopAgent sees state s → action a → environment gives new state s′ and reward r → learn, repeat.
WordsState s, action a, reward r, policy π, episode (one full try), return G, value, Q-value.
Policyπ(s, ai) = Pi; probabilities per state add to 1 (0.7 + 0.2 + 0.1). Learning = change probabilities toward rewarded actions.
ReturnG = r1 + γr2 + γ²r3 + … Rewards 0, 0, 10: γ 0.9 → 8.1; γ 0.5 → 2.5. γ near 1 patient; near 0 short-sighted.
ValueExpected return from a state. Corridor A-B-C(+10): V(B) = 10, V(A) = 9.
Explore / exploitε-greedy: explore (random) with prob. ε, else best action. ε 0.3, 3 actions: best 0.8, others 0.1, 0.1. ε 0.1, 2 actions: 0.95. Start large, shrink.
Q-learningQ(s,a) ← Q + α[r + γ max Q′ − Q]. α 0.5, γ 0.9: Q(B,right): 5, 7.5, 8.75, 9.375, 9.69 (→ 10); Q(A,right): 0, 2.25, 4.5, 6.19, 7.31 (→ 9). Reward news spreads backward.
Policy gradientBackprop needs the correct answer, RL does not have it. Guess → derivative → get reward → derivative × reward → gradient-descent step. Fries story: derivative 0.5 × reward +1 = 0.5; step 1.0 × 0.5. Negative reward flips direction.
UsesGames (self-play), robotics, driving/control, recommendation, language models.
ProblemsReward hacking (hides dirt under a rug), lots of trial and error, safe exploration, delayed reward / credit assignment, explainability.
Exam tipKnow the definition and vocabulary, write π(s, ai) = Pi, compute a discounted return, ε-greedy probabilities and one or two Q-learning updates by hand, and explain reward hacking.
