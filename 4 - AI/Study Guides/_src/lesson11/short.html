TopicRemember
OptimisationDecision variables + objective function (min f(x)) + constraints (hard gi(x) = ci; inequality hj(x) ≥ dj). Example: Max z = x², 0 ≤ x < 32.
Calculus wayf′(x*) = 0; f″ < 0 maxima, f″ > 0 minima. Fails when f′ is unknown / intractable.
Hill climbingStart x1, try small changes Δx, take the best; stop when no lesser local solution. Sensitive to initial conditions; traps in local minima.
Meta-heuristicStart with a population of feasible solutions, generate new ones in the neighbourhood, repeat until no improvement; answer = best in population at convergence. GA is one (others: PSO, ACO, SA, tabu…).
GA wordsPopulation N, chromosome (string), gene, allele (character values), phenotype (slides: each string), fitness = objective function, generation. Operators: selection, crossover, mutation. Holland's GA = binary strings.
Encode10010 = 16 + 2 = 18. n bits = 2n numbers. Donors 11011; real-coded (0.25, 1.73, …); TSP random keys. Shortest route fitness = 1 / distance.
LoopN, encoding, fitness → (selection → crossover → mutation) until population full → new population (kill weakest, constant size) → stop?
RouletteP(i) = f(i)/F. Slide: 20, 36, 16, 84, 124 (F = 280) = 7.1, 12.9, 5.7, 30.0, 44.3 %. Computer: running totals + random r. Max x² (4, 49, 256, 324; F = 633) = 0.6, 7.7, 40.4, 51.2 %.
TournamentPick two at random, keep the fitter.
CrossoverRandom cut; swap tails. 11000|000 × 11001|001 → 11000001, 11001000. D 10|010 × B 00|111 → 10111 (23), 00010. Cut point matters; only reshuffles existing genes.
MutationVery small pm; flip a gene (11000001 → 11010001). Needed to create new gene values (11110 can never become 11111 by crossover). Too little = stuck; too much = random.
TerminationSolution meets criteria; fixed generations; budget (time / money); fitness plateau; manual inspection; or a combination.
Worked x²01101, 11000, 01000, 10011: fitness 169, 576, 64, 361 (total 1170, avg 292.5); after one generation 12, 25, 27, 16: 144, 625, 729, 256 (total 1754, avg 438.5, best 729).
KnapsackWeights 1, 3, 5, 7, 9, 12; values 100, 300, 200, 500, 150, 400; cap 15. Chromosome 6 bits; fitness = value if weight ≤ 15 else 0. Best 011100 = 1000.
TSPOne-point crossover makes invalid routes (repeats / missing cities). Random keys: key in (0,1) per city, sort ascending: 0.42, 0.06, 0.38, 0.48, 0.81 → 2→3→1→4→5. Parameterised uniform crossover (gene from parent 1 with prob. p). Mutation = immigration (replace worst with new random set; avoids premature convergence).
OptimaGlobal best overall; local best nearby; near very close to global. Population + roulette + mutation help escape local hills.
Multi-objectiveTwo or more goals; conflict: f1 min at (1,1) where f2 = 13; f2 min at (0,−2) where f1 = 7; trade-offs, no single best.
Exam tipBe able to decode chromosomes, compute fitness and roulette probabilities, perform one crossover and mutation, run one generation and compare average fitness, decode random keys, and explain why a GA beats hill climbing (population, mutation, no derivative needed).
