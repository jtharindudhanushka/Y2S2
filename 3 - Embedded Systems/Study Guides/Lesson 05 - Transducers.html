Transducers: Sensors and Actuators

Covers lecture 06 and its datasheets: what a transducer is, digital sensors (reed switch, Hall effect, PIR, flame), analog sensors (water level, accelerometer, joystick), analog/digital sensors, actuators (RGB LED, bulb, motor, solenoid, thermoelectric), and how to drive heavy loads with a BJT (BC547), a MOSFET (2N7000), a flyback diode (1N4001) or a relay. Built from the slides, datasheets and peer note page 38.

Sources: lecture 06 (Transducers), datasheets for the AH1815 Hall switch, ADXL335 accelerometer, BC547 NPN transistor, 2N7000 MOSFET and 1N4001 diode, "Applications of Diodes" reference, peer note page 38 (only the PIR expansion was noted). The component values quoted come from those datasheets.

Learning outcomes

  • Explain the role of transducers and classify sensors (digital, analog, both) and actuators
  • Explain how common sensors capture the physical world and how common actuators change it
  • Interface sensors and actuators with an ATmega328P, including loads that need more than a pin can supply
  • Design a transistor / MOSFET / relay driver and explain the flyback diode

1. What is a transducer?

  • Converts energy or physical quantities from one form to another.
  • Used at the boundary of an embedded system.
  • Classified by the direction of conversion: sensors (physical quantity → electrical signal, inputs) and actuators (electrical energy → other forms, outputs).

2. Sensors

Sensors capture the state of the physical world as inputs. They are digital (two discrete voltages, read through a digital input pin with PINx / digitalRead), analog (a continuous voltage, read with the ADC) or both.

3. Actuators

Actuators convert electrical energy into other forms and change the state of the physical world. Many need a higher voltage or more current than an I/O pin can deliver.

The ATmega328P pin limits: about 20 mA per pin recommended (40 mA absolute maximum), about 200 mA total for the chip. A small DC motor, a relay coil, a solenoid or a bulb will exceed this, so a driver is needed.

4. Driving a load with a BJT (BC547)

  • An NPN BJT is a current-controlled switch: a small base current lets a much larger current flow from collector to emitter. (PNP is the complementary type.)
  • Circuit: microcontroller pin → base resistor RB → base; emitter to GND (common with the microcontroller); load between the load supply +V and the collector.
  • Flyback diode across an inductive load (motor, relay, solenoid): cathode to +V, anode to the collector. When the transistor switches off, the coil's collapsing field drives current back through the diode instead of producing a high voltage spike that could destroy the transistor or the pin. The kit uses a 1N4001 rectifier diode (50 V reverse, 1 A forward, about 1.1 V forward drop).

Choosing RB

To saturate the transistor (fully on) force the base current to about one tenth of the collector current: IB ≈ IC / 10 (less than the gain hFE, which is 110 or more for a BC547). Then RB = (Vpin − VBE) / IB with Vpin = 5 V and VBE ≈ 0.7 V.

Worked exampleA 6 V motor draws 100 mA. IB = 100 mA / 10 = 10 mA. RB = (5 − 0.7) / 0.010 = 430 Ω, use 330 Ω or 470 Ω (the pin supplies 13 mA at 330 Ω, still within the pin limit). With 1 kΩ the base current is 4.3 mA, which saturates the transistor only up to about 43 mA. The BC547 handles up to 100 mA continuous (45 V VCEO); above that choose a power transistor.

5. Driving a load with a MOSFET (2N7000)

  • An N-channel enhancement MOSFET is voltage controlled: the gate draws practically no current in steady state. Terminals: gate G, drain D (load side), source S (to GND).
  • 2N7000: 60 V drain-source, 200 mA continuous, gate threshold 0.8 to 3 V, so a 5 V pin turns it on fully (logic-level). On-resistance a few ohms at VGS = 4.5 to 10 V.
  • Wiring: pin → gate (optionally through about 100 Ω to limit switching current); a 10 kΩ pull-down from gate to GND keeps it off while the pin floats (during reset or programming); load from +V to drain; source to GND; flyback diode across inductive loads.

6. Switching with a relay

  • A relay is an electromagnetic switch. A small coil current (from a transistor driver) closes the contacts of a separate, isolated circuit, so the microcontroller never touches the load voltage.
  • Contacts: COM (common), NO (normally open), NC (normally closed). The coil needs a transistor driver and a flyback diode. Relay modules include the transistor, diode and an indicator LED.
  • Use a relay (or a solid-state relay) for AC mains loads. Only with qualified supervision, correct isolation and enclosure.

7. Reading a digital sensor (code pattern)

// Hall switch AH1815 on PD2 (output low when a magnet is near), motor driver on PB0
DDRB |=  (1<<DDB0);                  // motor transistor base
DDRD &= ~(1<<DDD2);                  // sensor input
PORTD |= (1<<PORTD2);                 // pull-up for the open-drain output
while (1) {
    if ((PIND & (1<<PIND2)) == 0)     // magnet present
        PORTB |=  (1<<PORTB0);        // motor on
    else
        PORTB &= ~(1<<PORTB0);        // motor off
}
// Arduino
void setup() { pinMode(8, OUTPUT); pinMode(2, INPUT_PULLUP); }
void loop()  { digitalWrite(8, digitalRead(2) == LOW); }

8. Diode applications (reference reading)

  • Rectification (1N400X series): AC to DC; 1N4001 withstands 50 V reverse and 1 A.
  • Flyback / freewheeling protection across relay coils, motors and solenoids.
  • Reverse-polarity protection in series with a battery input.
  • LED indicators (light emitting diodes), signal clamping and logic.
Common mistakes1) Driving a motor straight from a pin. 2) Forgetting the flyback diode or fitting it backwards. 3) Not joining the grounds of the motor supply and the Arduino. 4) Using no pull-down on a MOSFET gate. 5) RB too large to saturate the BJT, which makes it hot. 6) Powering a motor from the 5 V pin of the Arduino (use a separate supply). 7) Connecting a mains circuit on a breadboard.

Written questions

W1. Classify sensors with two examples of each class and explain how each class is read by the microcontroller.

Digital sensors (reed switch, Hall effect switch, PIR, flame) give two discrete voltages and are read on a digital pin with PINx / digitalRead (pull-up for open-drain or switch types). Analog sensors (water level, accelerometer, joystick, LDR, LM35) give a continuous voltage and are read by the ADC. Analog/digital sensors (sound, soil moisture, gas/smoke modules) provide both a continuous voltage and a threshold output.

W2. A 6 V DC motor (150 mA) must be switched on and off from a 5 V pin. Design the driver with a BC547 and justify the component values.

Pin → RB → base; emitter to GND (common with the Arduino); motor from the 6 V (or 9 V) supply to the collector; 1N4001 across the motor with the cathode to +V. Saturation needs IB ≈ 150/10 = 15 mA, RB = (5 − 0.7)/0.015 = 287 Ω, use 270 Ω; but the pin limit is about 20 mA, so a MOSFET (2N7000 has 200 mA limit and negligible gate current) is the better driver. The flyback diode absorbs the spike when the motor coil is switched off.

W3. Explain how a relay allows a microcontroller to control a mains lamp, and the precautions needed.

The pin switches a transistor that energises the relay coil (flyback diode across the coil). The relay contacts (COM and NO) are a separate circuit in series with the lamp's live wire, so the mains is isolated from the microcontroller. Precautions: qualified supervision, rated contacts, fuse, insulated enclosure, correct isolation, no breadboard or exposed wiring for mains.

W4. Compare BJT and MOSFET switches for a microcontroller load.

The BJT (BC547) is current controlled and needs a base resistor sized for IB ≈ IC/10; limit 100 mA. The MOSFET (2N7000) is voltage controlled, draws almost no gate current, switches faster (good for PWM), limit 200 mA; add a gate pull-down. Both need a flyback diode for inductive loads and a shared ground.

Practical question: "Magnetic lid pump" (exam style)

Original practice question using the kit parts named in the course (AH1815 / reed switch, BC547, 2N7000, 1N4001, 6 to 9 V DC motor, 9 V battery).

ScenarioA small pump (6 V DC motor, 120 mA) must run only while a magnet fixed to a tank lid is close to a Hall sensor (lid closed). When the lid is lifted the pump must stop immediately. A green LED shows that the pump is running. The motor has its own 9 V battery.
  1. Choose and justify a driver (BJT or MOSFET) and calculate its component values.
  2. Give the complete connection list (Arduino Uno, AH1815, driver, motor, diode, LED).
  3. Write the firmware in C using register access.
  4. Write the firmware with the Arduino wrapper functions.
  5. State two reasons the pump must not be connected directly to an I/O pin and one safety feature in the circuit.
Solution

1. Driver

BJT BC547 (100 mA limit) is too small for 120 mA. Use the 2N7000 MOSFET (60 V, 200 mA, gate threshold 0.8 to 3 V so a 5 V pin enhances it fully). Gate resistor 100 Ω (limits switching current), 10 kΩ pull-down from gate to GND so the pump stays off while the pin floats. 1N4001 flyback diode across the motor, cathode to the battery +. (If only BC547 parts are available: IB = 120/10 = 12 mA, RB = (5 − 0.7)/0.012 = 358 Ω, so 330 Ω, but the transistor is then at its limit, so a power transistor is preferred.)

3. C firmware

#include <avr/io.h>

int main(void)
{
    DDRB  |= (1<<DDB0) | (1<<DDB1);      // pump driver, LED
    DDRD  &= ~(1<<DDD2);                 // PD2 input (Hall sensor)
    PORTD |=  (1<<PORTD2);                // pull-up (open-drain output)
    while (1)
    {
        if ((PIND & (1<<PIND2)) == 0)    // output low: magnet near, lid closed
            PORTB |=  (1<<PORTB0) | (1<<PORTB1);    // pump and LED on
        else
            PORTB &= ~((1<<PORTB0) | (1<<PORTB1)); // both off
    }
}

4. Arduino firmware

const int sensor = 2, pump = 8, led = 9;
void setup() {
  pinMode(sensor, INPUT_PULLUP);
  pinMode(pump, OUTPUT);
  pinMode(led, OUTPUT);
}
void loop() {
  bool lidClosed = (digitalRead(sensor) == LOW);
  digitalWrite(pump, lidClosed);
  digitalWrite(led,  lidClosed);
}

5. Why not directly

(a) The motor draws 120 mA but an I/O pin can supply only about 20 mA (40 mA absolute maximum), so the pin or chip would be damaged. (b) The motor is an inductive load that generates voltage spikes when switched off, which could destroy the pin. Safety feature: the flyback diode (and the separate battery with a common ground).

Marking hintsDriver chosen with a calculation; flyback diode orientation; gate pull-down; common ground; pull-up for the open-drain Hall output and the active-low test; the code reacts immediately to the sensor state.
