Practical question: "Magnetic lid pump" (exam style)

Original practice question using the kit parts named in the course (AH1815 / reed switch, BC547, 2N7000, 1N4001, 6 to 9 V DC motor, 9 V battery).

ScenarioA small pump (6 V DC motor, 120 mA) must run only while a magnet fixed to a tank lid is close to a Hall sensor (lid closed). When the lid is lifted the pump must stop immediately. A green LED shows that the pump is running. The motor has its own 9 V battery.
  1. Choose and justify a driver (BJT or MOSFET) and calculate its component values.
  2. Give the complete connection list (Arduino Uno, AH1815, driver, motor, diode, LED).
  3. Write the firmware in C using register access.
  4. Write the firmware with the Arduino wrapper functions.
  5. State two reasons the pump must not be connected directly to an I/O pin and one safety feature in the circuit.
Solution

1. Driver

BJT BC547 (100 mA limit) is too small for 120 mA. Use the 2N7000 MOSFET (60 V, 200 mA, gate threshold 0.8 to 3 V so a 5 V pin enhances it fully). Gate resistor 100 Ω (limits switching current), 10 kΩ pull-down from gate to GND so the pump stays off while the pin floats. 1N4001 flyback diode across the motor, cathode to the battery +. (If only BC547 parts are available: IB = 120/10 = 12 mA, RB = (5 − 0.7)/0.012 = 358 Ω, so 330 Ω, but the transistor is then at its limit, so a power transistor is preferred.)

3. C firmware

#include <avr/io.h>

int main(void)
{
    DDRB  |= (1<<DDB0) | (1<<DDB1);      // pump driver, LED
    DDRD  &= ~(1<<DDD2);                 // PD2 input (Hall sensor)
    PORTD |=  (1<<PORTD2);                // pull-up (open-drain output)
    while (1)
    {
        if ((PIND & (1<<PIND2)) == 0)    // output low: magnet near, lid closed
            PORTB |=  (1<<PORTB0) | (1<<PORTB1);    // pump and LED on
        else
            PORTB &= ~((1<<PORTB0) | (1<<PORTB1)); // both off
    }
}

4. Arduino firmware

const int sensor = 2, pump = 8, led = 9;
void setup() {
  pinMode(sensor, INPUT_PULLUP);
  pinMode(pump, OUTPUT);
  pinMode(led, OUTPUT);
}
void loop() {
  bool lidClosed = (digitalRead(sensor) == LOW);
  digitalWrite(pump, lidClosed);
  digitalWrite(led,  lidClosed);
}

5. Why not directly

(a) The motor draws 120 mA but an I/O pin can supply only about 20 mA (40 mA absolute maximum), so the pin or chip would be damaged. (b) The motor is an inductive load that generates voltage spikes when switched off, which could destroy the pin. Safety feature: the flyback diode (and the separate battery with a common ground).

Marking hintsDriver chosen with a calculation; flyback diode orientation; gate pull-down; common ground; pull-up for the open-drain Hall output and the active-low test; the code reacts immediately to the sensor state.
