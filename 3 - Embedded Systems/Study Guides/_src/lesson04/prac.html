Practical question: "Cold-store monitor" (exam style)

Original practice question modelled on Exercises 4 and 6 (transducer, ADC, decision, actuator).

ScenarioA vaccine fridge must stay between 2 °C and 8 °C. A "cold-store monitor" reads an LM35 temperature sensor. A green LED is on while the temperature is 2 °C or higher and 8 °C or lower, an orange LED is on above 8 °C up to 12 °C, and a red LED is on above 12 °C or below 2 °C. Readings must be accurate to about 0.1 °C.
  1. Explain which ADC reference voltage you will choose and calculate the resulting resolution in °C per step.
  2. Draw the connection table for the Arduino Uno (LM35, three LEDs).
  3. Write the firmware in C (no wrapper functions).
  4. Write the firmware with the Arduino wrapper functions.
  5. The LM35 is 3 m from the board. Suggest a hardware improvement for noise.
Solution

1. Reference voltage

The LM35 gives 10 mV/°C, so 0 to 15 °C is only 0 to 0.15 V. With 5 V the step is 4.88 mV = 0.49 °C, which is too coarse. The internal 1.1 V reference (REFS1 = REFS0 = 1) gives 1.1 / 1024 = 1.074 mV = 0.107 °C per step, which meets 0.1 °C. Temperature = ADCW × 1.1 / 1024 × 100 = ADCW × 0.1074.

2. Connections

PartConnection
LM35 +V / Vout / GND5 V / A0 (PC0, ADC0) / GND
Green LEDpin 8 (PB0) → 220 Ω → LED → GND
Orange LEDpin 9 (PB1) → 220 Ω → LED → GND
Red LEDpin 10 (PB2) → 220 Ω → LED → GND

3. C firmware

#include <avr/io.h>

static float readTemp(void)
{
    ADCSRA |= (1<<ADSC);                       // start conversion
    while (ADCSRA & (1<<ADSC));                // wait
    return ADCW * 1.1 / 1024 * 100;            // degrees Celsius
}

int main(void)
{
    DDRB |= (1<<DDB0) | (1<<DDB1) | (1<<DDB2);   // LEDs
    DDRC &= ~(1<<DDC0);                          // PC0 input
    ADMUX  = (1<<REFS1) | (1<<REFS0);              // Vref = 1.1 V internal, channel ADC0
    ADCSRA = (1<<ADEN) | (1<<ADPS2) | (1<<ADPS1) | (1<<ADPS0);   // enable, F_CPU/128
    readTemp();                                // discard first reading after changing Vref
    while (1)
    {
        float t = readTemp();
        PORTB &= ~((1<<PORTB0) | (1<<PORTB1) | (1<<PORTB2));   // all off
        if (t > 12 || t < 2)       PORTB |= (1<<PORTB2);       // red
        else if (t > 8)            PORTB |= (1<<PORTB1);       // orange
        else                       PORTB |= (1<<PORTB0);       // green
    }
}

4. Arduino firmware

const int green = 8, orange = 9, red = 10;
void setup() {
  analogReference(INTERNAL);                 // 1.1 V
  pinMode(green, OUTPUT); pinMode(orange, OUTPUT); pinMode(red, OUTPUT);
}
void loop() {
  float t = analogRead(A0) * 1.1 / 1024 * 100;
  digitalWrite(red,    (t > 12 || t < 2));
  digitalWrite(orange, (t > 8 && t <= 12));
  digitalWrite(green,  (t >= 2 && t <= 8));
  delay(500);
}

5. Noise

Put a 100 nF capacitor between the ADC input and GND next to the board, use shielded or twisted cable, and average several readings (for example 16) in firmware.

Marking hints1.1 V reference justified with the number; ADCW × 1.1 / 1024 × 100 (floats and 1024); ADEN, prescaler, ADSC polling; correct boundaries for each band, including both below 2 and above 12; Vref switch noted.
