ADC mathsIntervals = 2^n = 1024. ΔV = Vref/1024. ADCW = floor(Vin/ΔV). Vin = ADCW × Vref/1024. Use 1024. 5 V: 4.883 mV; 1.1 V: 1.074 mV.
AccuracyMore bits or smaller Vref.
ADMUXREFS1 REFS0: 00 AREF, 01 AVcc, 11 1.1 V. ADLAR left adjust. MUX3..0 channel (0000 = ADC0 ... 0101 = ADC5, 1000 = temperature).
ADCSRAADEN (7), ADSC (6), ADATE (5), ADIF (4), ADIE (3), ADPS2..0 (2..0). 111 = /128 = 125 kHz.
Read stepsinput pin, Vref, channel, prescaler, ADEN, ADSC, wait ADSC = 0 (or ADC_vect), read ADCW.
ArduinoanalogRead(A0) = 0..1023; analogReference(DEFAULT / INTERNAL / EXTERNAL).
LDRResistance falls with light; divider Vin = V×R2/(R1+R2). LDR on top: bright = high Vin. Use hysteresis (on < 300, off > 400).
LM3510 mV/°C; T = Vout × 100; with 1.1 V Vref: T = ADCW × 0.1074; −55 to 150 °C.
VoltmetervIn = ADCW * 5.0 / 1024; >4 5 LEDs, >3 4, >2 3, >1 2, >0 1.
Interrupt ADCADIE + sei(), start once, ISR(ADC_vect) uses ADCW and restarts with ADSC.
