PollingCPU checks devices repeatedly. Misses fast events, wastes CPU, no priority. Button tested with (PIND & (1<<PIND2)) == 0.
InterruptDevice interrupts CPU; return address pushed on stack; jump via vector table to ISR; RETI resumes. Priority by vector address (lower = higher).
C tools#include <avr/interrupt.h>; sei(), cli(); ISR(XXX_vect); volatile shared variables.
VectorsINT0_vect, INT1_vect, PCINT0/1/2_vect (B/C/D), TIMER0/1/2_OVF_vect, USART_RX_vect, USART_UDRE_vect, USART_TX_vect, ADC_vect.
External INTINT0 = PD2, INT1 = PD3. EICRA: ISCn1 ISCn0 = 00 low, 01 change, 10 falling, 11 rising. EIMSK bit INTn enables.
Pin changePCICR PCIE0/1/2 (B/C/D) + PCMSKn bit. PD2 = PCINT18 (PCMSK2). Fires on any change, so test the pin in the ISR.
