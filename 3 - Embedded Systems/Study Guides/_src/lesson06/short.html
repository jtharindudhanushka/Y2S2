TopicRemember
Timer vs counterTimer counts oscillator pulses (time), counter counts external pulses on Tn (events). Peripheral so the CPU is free.
TimersT0, T2: 8-bit (255). T1: 16-bit (65 535). T0 pin PD4, T1 pin PD5.
Formulastick = prescale/F_CPU; n = (F_CPU/prescale) × delay; initial = max − n + 1; elapsed = N×(B−A)/f.
CS bits001 /1, 010 /8, 011 /64, 100 /256, 101 /1024, 110 external falling, 111 external rising, 000 stopped.
FlagTOVn in TIFRn, cleared by writing 1. TOIEn in TIMSKn enables TIMERn_OVF_vect; cleared automatically on interrupt entry.
Ready values200 ms T1 /64: 15 536. 1 s T1 /1024: 49 911. 5 counts T0: 251. 10 ms T0 /1024: 156 counts, initial 100.
OverflowT1 /64: 262 ms; T1 /1024: 4.19 s; T0 /1024: 16.4 ms.
PatternSet CS, load TCNT, poll TOV (or TOIE + sei), reload TCNT, clear TOV.
Randomstdlib.h: srand(seed), rand(); 1 + rand() % 10. Seed from TCNT0 at a button press or from a floating ADC pin. Arduino: randomSeed, random(min,max).
Reaction timerReady, react buttons; blue signal LED; green < 1 s, orange 1 to < 2 s, red ≥ 2 s; T1 overflow = 1 s.
