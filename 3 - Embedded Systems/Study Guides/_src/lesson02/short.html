TopicRemember
RegistersDDR 1 = output, 0 = input. PORT writes outputs (and enables the pull-up for inputs). PIN reads inputs.
LED resistorR = (Vs − VL) / IL; round up to the standard value (200 → 220 Ω).
Colour code0 black, 1 brown, 2 red, 3 orange, 4 yellow, 5 green, 6 blue, 7 violet, 8 grey, 9 white; third band = multiplier.
Bit operationsset |= (1<<n); clear &= ~(1<<n); toggle ^= (1<<n); test PINx & (1<<n).
ButtonPin to GND, PORT bit = 1 for pull-up, pressed reads 0.
Delay mathst = 1/f (16 MHz: 62.5 ns); cycles = delay/t (0.5 s: 8 000 000). Loop of N: (b+1+2)(N−1) + (b+1+1). LDI 1, DEC 1, BRNE 2/1, NOP 1, RET 4, CALL 4.
Exact delays500 ms: R16=72, R17=188, R18=196 + 8 NOP. 200 ms: 241, 25, 176 + 2 NOP.
Asm blinkerSBI DDRB,0; START: SBI PORTB,0; CALL DELAY; CBI PORTB,0; CALL DELAY; JMP START.
C blinker#define F_CPU before util/delay.h; DDRB|=; while(1){...}.
ArduinopinMode / digitalWrite / digitalRead / delay; INPUT_PULLUP. Larger HEX (920 B vs 200 B vs 172 B for the 5-LED chaser).
ComparisonAsm: efficient, hard, not portable. C: efficient, easier, portable. Arduino: easiest, inefficient.
