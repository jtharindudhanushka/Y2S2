Practical question: "Scanner light" (exam style)

Original practice question modelled on Exercises 1 and 2 and on the style of the past practical paper (assemble the hardware, then write and demonstrate the firmware).

ScenarioA "scanner light" sweeps a single lit LED across a row of six LEDs (left to right, then right to left, without repeating the end LEDs). Each LED stays lit for 150 ms. When the operator holds the "fast" pushbutton the sweep runs at 50 ms per LED instead. The LEDs are driven at 2 V and 12 mA from a 5 V supply.
  1. Calculate the series resistor and prepare a Bill of Materials.
  2. Assemble the system on a breadboard with an Arduino Uno (ATmega328P). Give a wiring table: pins, port bits and components.
  3. Write the firmware using the Arduino wrapper functions.
  4. Write the firmware in C using direct register access and the labelled constants (DDB0, PORTB0, PIND2).
  5. The sketch for part 3 is 1 020 bytes and the C code is 210 bytes. Explain the difference.
Solution

1. Resistor and BOM

R = (5 − 2) / 0.012 = 250 Ω. Use the next standard value, 270 Ω (about 11 mA); 220 Ω (13.6 mA) is acceptable if the LED allows 15 mA.

2. Wiring

Arduino pinPort bitConnection
8 to 13PB0 to PB5Each pin → 270 Ω → LED anode; LED cathodes to the GND rail
2PD2One leg of the pushbutton; the other leg to GND. Internal pull-up is used (no resistor).
GNDCommon ground rail

Pin 13 already has the on-board LED, so the on-board LED will blink too; that is harmless. Do not use pins 0 and 1.

3. Arduino wrapper version

const int led[] = {8, 9, 10, 11, 12, 13};
const int btn = 2;

void setup() {
  for (int i = 0; i < 6; i++) pinMode(led[i], OUTPUT);
  pinMode(btn, INPUT_PULLUP);
}

void show(int i) {
  int d = (digitalRead(btn) == LOW) ? 50 : 150;   // pressed = fast
  digitalWrite(led[i], HIGH);
  delay(d);
  digitalWrite(led[i], LOW);
}

void loop() {
  for (int i = 0; i < 6; i++)  show(i);          // left to right
  for (int i = 4; i > 0; i--)  show(i);          // back, ends not repeated
}

4. C version

#include <avr/io.h>
#define F_CPU 16000000UL
#include <util/delay.h>

static void show(int i)
{
    PORTB = (1<<i);                                  // only LED i on
    if ((PIND & (1<<PIND2)) == 0) _delay_ms(50);    // fast
    else                            _delay_ms(150);
}

int main(void)
{
    DDRB  |= 0b00111111;            // PB0..PB5 outputs
    DDRD  &= ~(1<<DDD2);           // PD2 input
    PORTD |=  (1<<PORTD2);          // pull-up
    while (1)
    {
        for (int i = 0; i < 6; i++)  show(i);
        for (int i = 4; i > 0; i--)  show(i);
    }
}

Note: _delay_ms() needs a compile-time constant argument, which is why the two branches each call it with a literal.

5. Size difference

The wrapper version links pinMode, digitalRead, digitalWrite, delay, the pin-to-port tables, PWM-turn-off checks and the core start-up (init(), timer set-up, the millis() interrupt). The C version writes the registers directly and contains only the instructions it needs.
