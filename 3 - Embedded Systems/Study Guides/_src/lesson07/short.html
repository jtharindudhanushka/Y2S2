Short note: revision sheet

TopicRemember
PWMAnalog-like output by digital means; device reacts to the average. Duty = thigh/period; Vavg = duty × 5 V.
GenerationTCNT counts 0..TOP; comparator vs OCRnX; waveform generator sets/clears OCnX. Non-inverted (COM = 10): clear at match, set at 0. Inverted (11): set at match, clear at 0.
FrequencyFPWM = F_CPU/((TOP+1) × prescale). 8-bit /64: 976.6 Hz. Phase correct: F_CPU/(510 × prescale) = 490 Hz.
DutyFast: (OCR+1)/(TOP+1). Phase correct: about OCR/TOP.
WGM (n2 n1 n0)000 Normal, 001 Phase correct PWM, 010 CTC (TOP = OCRnA), 011 Fast PWM.
CTCCount to OCRnA, clear, OCFnA flag, OCIEnA interrupt. 1 ms at /64: OCR = 249.
PinsOC0A = PD6 (6), OC0B = PD5 (5), OC1A = PB1 (9), OC1B = PB2 (10), OC2A = PB3 (11), OC2B = PD3 (3). Output in DDR.
1 kHz recipeDDRD |= (1<<DDD6); TCCR0A = (1<<COM0A1)|(1<<WGM01)|(1<<WGM00); TCCR0B = (1<<CS01)|(1<<CS00); OCR0A = value;
ArduinoanalogWrite(pin, 0..255) on ~ pins; 5, 6 about 977 Hz fast PWM, others about 490 Hz phase correct.
Analog outputMCU with DAC, DAC breakout, or RC low-pass filter.
Auto fanLM35 on A0, 1.1 V reference; duty 0 at ≤ 25 °C, 255 at ≥ 35 °C, linear (T−25)/10 × 255; motor via BC547/2N7000, flyback diode, common ground.
