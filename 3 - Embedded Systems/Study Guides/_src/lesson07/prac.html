Practical question: "Twin-lamp dimmer" (exam style)

Original practice question modelled on the fader and Exercise 6 (ADC in, PWM out) and using the inverted mode of the compare output.

ScenarioA reading lamp has a bright LED and a night-light LED. A potentiometer sets the main LED brightness from off to full. The night-light LED does the opposite: it is brightest when the main LED is off and off when the main LED is at full brightness. Both are driven by PWM at about 1 kHz from the two outputs of the same timer.
  1. Choose the timer, mode and prescaler, and calculate the PWM frequency.
  2. Give the connection list.
  3. Write the firmware in C. Use the inverted output mode for the night light.
  4. Write the firmware with the Arduino wrapper functions.
  5. What duty cycle does each LED get when the potentiometer is at the middle (ADC = 512)?
Solution

1. Timer

Timer0 in fast PWM (WGM02:0 = 011), prescale 64 (CS02:0 = 011). FPWM = 16 MHz / (256 × 64) = 976.6 Hz ≈ 1 kHz. Outputs: OC0A = PD6 (pin 6, main LED, non-inverted, COM0A1:0 = 10) and OC0B = PD5 (pin 5, night light, inverted, COM0B1:0 = 11). The same OCR value then gives opposite brightness: duty A = (OCR + 1)/256, duty B = 1 − (OCR + 1)/256.

2. Connections

PartConnection
10 kΩ potentiometerends to 5 V and GND, wiper to A0 (PC0)
Main LEDpin 6 (PD6) → 220 Ω → LED → GND
Night LEDpin 5 (PD5) → 220 Ω → LED → GND

3. C firmware

#include <avr/io.h>

int main(void)
{
    DDRD  |= (1<<DDD6) | (1<<DDD5);                     // OC0A, OC0B outputs
    TCCR0A = (1<<COM0A1)                                 // OC0A non-inverted (10)
           | (1<<COM0B1) | (1<<COM0B0)                  // OC0B inverted (11)
           | (1<<WGM01)  | (1<<WGM00);                  // fast PWM
    TCCR0B = (1<<CS01) | (1<<CS00);                     // /64, 976.6 Hz
    ADMUX  = (1<<REFS0);                                 // AVcc, channel ADC0
    ADCSRA = (1<<ADEN) | (1<<ADPS2) | (1<<ADPS1) | (1<<ADPS0);
    while (1)
    {
        ADCSRA |= (1<<ADSC);
        while (ADCSRA & (1<<ADSC));
        unsigned char v = ADCW >> 2;                     // 10-bit to 8-bit (0..255)
        OCR0A = v;                                       // main LED
        OCR0B = v;                                       // night light (inverted output)
    }
}

4. Arduino firmware

const int mainLed = 6, nightLed = 5;
void setup() { pinMode(mainLed, OUTPUT); pinMode(nightLed, OUTPUT); }
void loop() {
  int v = analogRead(A0) / 4;          // 0..255
  analogWrite(mainLed, v);
  analogWrite(nightLed, 255 - v);      // analogWrite is non-inverted, so invert in software
}

5. Middle position

ADC = 512 gives OCR = 512 >> 2 = 128. Main LED: duty = (128 + 1)/256 = 50.4 %. Night LED (inverted): 1 − 129/256 = 49.6 % (about half each).
