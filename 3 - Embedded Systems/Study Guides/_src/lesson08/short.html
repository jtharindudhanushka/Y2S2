Short note: revision sheet

TopicRemember
Serial vs parallelSerial = 1 bit at a time, few wires. Parallel needs many wires, has skew and crosstalk.
Async frameIdle high; start bit 0; data LSB first; stop bit 1. 8N1 = 10 bits/char. Needs matching baud rate (no clock).
InterfacesRS-232 via MAX232 line driver (level shift). USB via UART-to-USB controller: FT232RL (Duemilanove), ATmega16U2 (Uno). TX to RX crossed, common GND.
TransmitUDRE (data register empty, max throughput) vs TXC (whole frame sent).
ReceiveRXC set when UDR has unread data; reading UDR clears it.
RegistersUCSR0A: RXC0 bit 7, TXC0 bit 6, UDRE0 bit 5. UCSR0B: RXCIE0 7, TXCIE0 6, UDRIE0 5, RXEN0 4, TXEN0 3, UCSZ02 2. UCSR0C: UCSZ01, UCSZ00 (011 = 8-bit).
BaudUBRR = F_CPU/(16×baud) − 1 (use UL). 9600 → 103 (+0.16 %); 19 200 → 51; 115 200 → 8 (−3.55 %, too high). Error = (actual − desired)/desired. 18.432 MHz gives 0 % at 9600.
C recipeUBRR0 = ...; UCSR0B &= ~(1<<UCSZ02); UCSR0C |= (1<<UCSZ01)|(1<<UCSZ00); UCSR0B |= (1<<RXEN0)|(1<<TXEN0); send: wait UDRE then UDR0 = c; receive: wait RXC then c = UDR0.
InterruptsUSART_RX_vect (RXCIE0), USART_UDRE_vect (UDRIE0, disable when done), USART_TX_vect (TXCIE0).
ArduinoSerial.begin(9600); Serial.available(); Serial.read(); Serial.print/println. Serial Monitor = terminal emulator.
CR / LF\r = 13 carriage return, \n = 10 line feed.
Strings'-55' / '150' need 3 chars + '\0' = 4 elements. itoa(n, buf, 10).
stdioFDEV_SETUP_STREAM(put, get, _FDEV_SETUP_RW); stdin = stdout = &stream; getchar/printf. Pros: portable, convenient; cons: memory, speed.
C# appSerialPort, DataReceived on another thread: use Invoke/BeginInvoke; send 'Y'/'N'; close port on exit.
2020 lecture: whySerial saves pins (8-bit parallel = 16 pins); crosstalk; separate USART frees the single slow CPU ("living on another planet").
2020 lecture: hardwareRS-232 1 = −3..−25 V, 0 = +3..+25 V → MAX232 (Severino); FT232 needs FTDI driver (Duemilanove); Uno R3 uses ATmega16U2 with its own crystal. TX→RX crossed. Nothing on D0/D1.
2020 lecture: exam whysBaud rates are multiples of 80 (80-char terminal lines); UL avoids 16-bit overflow (709 instead of 103); UDRE = max throughput, TXC = all sent (half-duplex, power off); error < 2.5%, 0% with 18.432 MHz.
