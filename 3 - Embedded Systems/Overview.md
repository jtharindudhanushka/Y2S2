# INTE 22263: Embedded Systems Development

- **Course Code:** INTE 22263
- **Course Title:** Embedded Systems Development
- **Prerequisites:** INTE 21243

---

## Learning Outcomes
After completing this module, the students should be able to:
1. Define embedded systems and their core characteristics.
2. Discuss the performance requirements and constraints of embedded systems.
3. Describe the architecture of embedded systems.
4. Enumerate and describe the core components of an embedded system.
5. Compare and contrast single-chip vs single-board computers-based implementations.
6. Explain the hardware and software co-design of embedded systems.
7. Evaluate different platforms available for embedded systems development.
8. Design, develop and debug embedded systems to automate real world tasks.

---

## Course Contents
Embedded system, requirements and constraints, evolution of embedded systems, embedded system architectures, single-chip and single-board computers, microcontrollers, microprocessors, special function registers, general purpose and input/output registers, transducers, hardware and software platforms, hardware software co-design, firmware, hardware programmers, bootloaders, embedded operating systems, Analog to Digital Conversion (ADC), polling and interrupt handling, timers and counters, Pulse Width Modulation (PWM), asynchronous and synchronous data communication, data acquisition and logging, hardware development, resource-aware firmware development, hardware programming, debugging and simulation, power management, performance evaluation, optimization, current trends and future insights.

---

## Assessment
- **End semester practical examination:** 50%
- **End semester written examination:** 50%
