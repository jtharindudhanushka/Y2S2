# INTE 22293: Software Architecture and Process Models

- **Course Code:** INTE 22293
- **Course Title:** Software Architecture and Process Models
- **Department:** Department of Industrial Management, University of Kelaniya

---

## Course Topics & Curriculum
1. **Introduction to Software Architecture:** Role of the architect, architectural quality attributes, structural views.
2. **Structure for Software & Good Design:** Coupling, cohesion, modularity, layering, architectural patterns.
3. **Systems Thinking & Design Thinking:** Holistic problem solving, context models, user-centric system design.
4. **C4 Model for Visualizing Software Architecture:** Context, Containers, Components, and Code diagrams.
5. **Full-Stack Monolithic Architecture Lab Series (UniMart):** Complete engineering walkthrough from ER diagram to React TypeScript frontend, Spring Boot MVC backend, MySQL, Postman API testing, Redux, and cloud deployment.
6. **Agile Process Models & Group Project:** Scrum workflows, Jira sprint management, GitHub version control, and multi-team service platform development.
