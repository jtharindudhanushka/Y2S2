Short note: revision sheet

TopicRemember
StackReact + TypeScript SPA (Vite, Redux Toolkit, MUI, Tailwind) → Spring Boot MVC REST API (Java 21, JPA/Hibernate, Flyway, Spring Security JWT) → MySQL 8.4; Nginx; Docker on one VPS.
ER design (guide 01)Entities: User, Category, Listing, ListingImage, Conversation, Message, Order, Payment, Review, Notification. DECIMAL for money; UNIQUE email, order_id on review, payment idempotency key; soft delete; status enums; constraints in service AND database.
DiagramsC4 context, container, component/package, deployment: one backend deployable, one DB, labelled arrows, security boundaries.
MVC mappingController = HTTP only; Service = rules, transactions, authorisation; Repository = data; Model = entities/DTOs; View = React.
Frontend (02)Feature-first folders; only VITE_ vars reach the browser (no secrets); MUI for components, Tailwind for layout.
Backend (03)Package-by-feature; thin controllers; DTOs not entities; global exception handler; 201/204/400/401/403/404/409; BCrypt; short JWTs; exact CORS.
MySQL (04)Least-privilege account (not root); utf8mb4; Flyway owns schema; backups with mysqldump.
Config (05)DB_URL, DB_USERNAME, DB_PASSWORD, JWT_SECRET (base64 32+ bytes), JWT_ACCESS_MINUTES, APP_ALLOWED_ORIGINS; .env.example committed, .env ignored; ddl-auto validate; migrations immutable (add new versions).
Git (06)Separate frontend / backend repos; feature branch + PR + review + CI; protected main; rebase local branches; ff-only pull; conventional commits; annotated tags.
CRUD (07)Listings and Reviews; validation DTOs; ownership checks (403); SOLD cannot be deleted (409); review needs COMPLETED order, buyer only, once (UNIQUE order_id); stateless JWT security chain; Postman negative tests.
Frontend features (08)RTK Query for server state (providesTags / invalidatesTags); slices for auth state; handle loading, empty, error states.
Integration (09)Access token in memory + HttpOnly refresh cookie; one refresh retry with mutex; Redux DevTools; CORS exact origin; error-to-fix matrix.
Deployment (10)Droplet + deploy user + UFW; multi-stage Dockerfiles (non-root); Compose with MySQL volume and healthcheck; Nginx reverse proxy + Certbot TLS; GitHub Actions test, build, push to GHCR, SSH deploy; rollback by SHA tag. Containers ≠ microservices: still one monolith.
Exam tipBe ready to explain WHY: monolith first for a small team, DTOs instead of entities, Flyway + validate, JWT stateless security, secrets in environment variables, and that Docker does not change the architecture style.
