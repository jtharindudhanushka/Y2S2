Short note: revision sheet

TopicRemember
Latency vs throughputLatency = wait for one operation (200 ms). Throughput = work per unit time (1,000 req/s). Batching buys throughput with latency. 100 ms extra latency about 1 % of sales (Amazon).
Why slowSlow queries, chatty calls, sequential work, large payloads, O(n²) algorithms, contention, external dependencies. Measure before optimising.
CachingHit ~1 ms, miss goes to the DB then stores the result. Cache read-often, change-rarely, expensive, stale-tolerant data. Catch: invalidation (menu 5 min; order status never). Redis, Memcached, CDN.
Load balancerSpreads requests, health-checks, hides failures. Needs any server to answer any request (stateless).
ScalingUp (bigger server; ceiling, still a SPOF) vs out (more machines; needs load balancer + stateless design).
StatelessEach request carries what the server needs (token). Fix session trap by shared session store (Redis) or stateless tokens (JWT).
Parallel / asyncSequential time = sum; parallel = slowest branch (600 ms to 200 ms). Async: queue email after order; never make the user wait for unseen work.
Availability99 % = 3.65 days; 99.9 % = 8.8 h; 99.99 % = 53 min; 99.999 % = 5 min per year. Each nine about 10x effort.
SPOF / redundancyAsk "what happens when this dies?" Load balancer + several app servers + DB primary/replica.
OutagesAWS S3 2017 (mistyped command; shared dependency = shared SPOF); Meta 2021 (network config; blast radius, independent recovery paths).
Partial failure toolsTimeout (deadline); retry (idempotent only, limit, backoff 1-2-4 s); circuit breaker (closed, open, half-open; Nygard, Release It!).
SecurityAuthN = who; AuthZ = what allowed (server-side every request). Never trust the client. TLS in transit, encrypt at rest, hash passwords (bcrypt / argon2: no way back). Parameterised queries stop SQL injection. Secrets in env, never in Git (.env ignored, .env.example committed).
Reuse ladderModule, package, library (you call it), framework (it calls you: inversion of control).
SQL vs NoSQLSQL: stable shape, joins, integrity, transactions. Document: varying shape, read whole. Key-value (Redis): carts, sessions. Wide-column (Cassandra): GPS streams. Choose per data shape.
Team agreementsNaming, formatting (Prettier / Black), error handling, definition of done (merged, reviewed, tested, documented).
Exam tipFor a quality-attribute question, name the tactic and its catch: cache (invalidation), horizontal scaling (needs stateless), retry (needs idempotency), circuit breaker (fail fast to a fallback), async (eventual completion).
