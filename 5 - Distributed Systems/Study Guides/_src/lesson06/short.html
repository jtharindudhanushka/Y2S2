Common mistakes

MistakeCorrect idea
A Pod is a containerA Pod wraps one or more containers that share an IP and volumes.
Containers in a Pod talk through a ServiceThey use localhost; Services are for reaching Pods from elsewhere.
Restart policy brings back a deleted PodIt only restarts containers in place; a Deployment recreates Pods.
emptyDir data survives Pod deletionIt survives container restarts but is deleted with the Pod.
Scheduler runs containers on nodesThe scheduler chooses the node; the kubelet and container runtime run them.
Network LB routes by URLApplication LB (layer 7) routes by URL/headers; network LB (layer 4) by IP/port.
Vertical scaling is preferred in the cloudHorizontal is preferred: availability and distribution.
IaC = writing application codeIaC = infrastructure defined in code files (Terraform, CloudFormation).
Cost-efficiency = lowest possible costBest value for the required performance and reliability.
