Common mistakes

MistakeCorrect idea
Mixing service models and deployment modelsService model = what is provided (IaaS/PaaS/SaaS). Deployment model = who owns/uses it (public/private/hybrid/community/multi).
"In IaaS the provider manages the OS."In IaaS you manage the OS and everything above it.
Hybrid = multi-cloudHybrid = private + public. Multi-cloud = several public providers.
"Serverless has no servers."Servers exist; you just don't manage them.
Listing "scalability" or "security" as a NIST characteristicThe five are on-demand self-service, broad network access, resource pooling, rapid elasticity, measured service.
"The provider is responsible for all security in the cloud."Shared responsibility: the customer secures data, IAM, network config, apps.
Containers contain their own OSThey share the host OS kernel; VMs have a full guest OS.
Edge = fogEdge is on/near the device (<10 ms); fog is a middle layer (10–50 ms) that aggregates edge data.
Spot instances for a critical always-on serverSpot can be reclaimed at any time; use it only for fault-tolerant work.
