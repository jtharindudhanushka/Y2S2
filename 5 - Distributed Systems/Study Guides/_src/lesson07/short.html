Common mistakes

MistakeCorrect idea
S3 has real foldersFlat namespace; "folders" are key prefixes.
Objects can be edited in placeObjects are immutable; an update rewrites the whole object.
Data in GFS flows through the MasterOnly metadata goes through the Master; data goes client ↔ chunkserver.
GFS block size 128 MB, HDFS 64 MBGFS 64 MB chunks; HDFS 128 MB blocks.
S3 is eventually consistentStrong read-after-write since December 2020.
Durability = availabilityDurability = not losing data; availability = being reachable now.
EBS can be shared by many instances like EFSEBS attaches to one instance (except io2 Multi-Attach); EFS is shared.
EBS survives an AZ failure automaticallyEBS is AZ-bound; use snapshots (stored in S3) to recover elsewhere.
HDFS is good for millions of tiny filesSmall-file problem: NameNode memory.
Erasure coding is freeSaves storage (~1.5×) but costs CPU for rebuilds.
