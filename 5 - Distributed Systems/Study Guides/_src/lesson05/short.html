Common mistakes

MistakeCorrect idea
Type 1 runs on top of WindowsType 1 runs on bare hardware; Type 2 runs on a host OS.
VirtualBox is a Type 1 hypervisorVirtualBox, Workstation and Parallels are Type 2.
Containers virtualize hardwareContainers virtualize the OS; VMs virtualize the hardware.
Containers are more isolated than VMsVMs have stronger isolation (separate kernel).
Virtualization removes single points of failure by itselfThe host/hypervisor is a SPOF for all its VMs; you still need multiple hosts/AZs.
Region = availability zoneA region contains several AZs.
Multi-tenancy means tenants can see each other's dataIsolation is enforced in software by the virtualization layer.
Hyperjacking = attacking one VMIt is compromising the hypervisor, which exposes all VMs.
