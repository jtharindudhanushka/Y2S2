Common mistakes

MistakeCorrect idea
Para-virtualization runs unmodified OSesPara-virtualization needs a modified guest kernel (hypercalls); full and hardware-assisted run unmodified OSes.
Binary translation is done by the CPUThe hypervisor (software) translates; hardware-assisted is the CPU-based approach.
Reboot after enabling VT-xSlide: you must POWER CYCLE, not just reboot.
EPT is for I/O devicesEPT/RVI = MMU (memory); VT-d/AMD-Vi = I/O.
LXC is a hypervisorLXC is OS-level (container) virtualization.
vMotion moves the VM's disksvMotion moves host (state); Storage vMotion moves disks between datastores.
vMotion needs downtimeIt is a live ("hot") migration with no downtime.
vSwitches learn MACs and run spanning treeThey know vNIC MACs already and do not run STP.
vmnic = virtual NICvmnic = physical NIC (uplink); vNIC = the VM's virtual NIC.
Using gateway 192.168.8.1 with IP 192.168.1.X/24The IP must be in the gateway's network: 192.168.8.X/24.
