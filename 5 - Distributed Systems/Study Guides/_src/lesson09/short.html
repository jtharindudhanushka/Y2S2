Common mistakes

MistakeCorrect idea
Consensus needs every node to agree before decidingPaxos/Raft need only a majority; 2PC needs everyone.
Raft can have two leaders in the same termAt most one leader per term (one vote per server per term, majority needed).
Chord stores key k at the node before kAt its successor: the first node with ID ≥ k.
Flooding always finds the fileOnly within the TTL; rare items may be missed.
DHTs support keyword search nativelyThey support exact-key lookup; keyword search needs extra indexing.
An inverted index maps documents to wordsIt maps words (terms) to documents (posting lists).
MapReduce is good for low-latency queriesIt is a high-throughput batch model.
Reactive agents plan aheadReactive = condition–action rules; deliberative agents plan (BDI); hybrid combines them.
