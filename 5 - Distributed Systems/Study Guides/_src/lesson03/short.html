ProsLess space, power, maintenance & HW cost; easier upgrades; longer HW life; manage from anywhere
StackMANO (orchestration) · VNFs · NFVI (+ SDN, VIM)

Why SDNWAN cost, hybrid/multi-cloud control, prioritise critical traffic, new sites fast, security, multi-domain, future-proof

Common mistakes

MistakeCorrect idea
NFV = virtualizing the whole networkNFV virtualizes network functions only (the slide stresses this).
NFV and SDN are the same thingNFV = functions as software; SDN = control plane separated and centralized.
Image and container used as synonymsImage = read-only template; container = running instance of it.
Storing database files inside a containerContainers are ephemeral; use volumes for persistent data.
Swapping RTO and RPORTO = time to recover (downtime). RPO = point in time recovered to (data loss).
Pilot light = warm standbyPilot light: only data live, servers off. Warm standby: small but fully working copy running.
"One AZ is enough if the server is big."One AZ is a single point of failure; use at least two.
Vertical scaling = adding serversVertical = bigger instance; horizontal = more instances.
Putting databases in a public subnetKeep app servers and databases in private subnets; only the load balancer faces the Internet.
