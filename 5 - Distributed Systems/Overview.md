# INTE 22253: Distributed Systems and Cloud Computing

- **Course Code:** INTE 22253
- **Course Title:** Distributed Systems and Cloud Computing
- **Department:** Department of Industrial Management, University of Kelaniya

---

## Course Topics & Curriculum
1. **Introduction to Distributed Systems:** Characterization, design goals, challenges (heterogeneity, openness, scalability, concurrency, transparency).
2. **Cloud Computing Fundamentals:** Deployment models (Public, Private, Hybrid), service models (IaaS, PaaS, SaaS).
3. **Virtualization & Containerization:** Hypervisors, virtual machines, container technology, container orchestration.
4. **Cloud Infrastructure & Networking:** Resource provisioning, load balancing, cloud storage systems, cloud security.
5. **Practical Labs & Assignments:** Cloud environment setup, distributed application deployment, virtualization lab sheets.
